These are local copies of provider brand icons used in the official API selector. They are bundled with the desktop app so the selector does not need a network connection. UniCompAPI reuses the desktop app's project logo at `../../brand-logo.png`.

- `alibaba-cloud.svg`: Alibaba Cloud mark from Simple Icons (`alibabacloud`, color `FF6A00`); used for Wanx and Bailian.
- `deepseek.svg`: DeepSeek mark from Simple Icons (`deepseek`, color `5786FE`).
- `kimi.svg`: Kimi mark from Simple Icons (`kimi`); used for Moonshot's Kimi API.
- `minimax.svg`: MiniMax mark from Simple Icons (`minimax`, color `E73562`); shared by video and speech.
- `openai.svg`: OpenAI symbol from Iconify's `logos` icon set (`openai-icon`).
- `sync.png`: https://sync.so/favicon.ico.
- `vidu.svg`: https://www.vidu.cn/logo.svg; shared by Vidu China and global endpoints.
- `volcengine.png`: https://portal.volccdn.com/obj/volcfe/misc/favicon.png; used for Seedance.
- `zhipu.png`: https://open.bigmodel.cn/static/images/favicon.png.
