This application distributes unmodified FFmpeg and ffprobe built by BtbN,
version n8.1.3-9-g29e619e767-20260930, Windows x64 LGPL shared variant.
Copyright (c) 2000-2026 the FFmpeg developers. https://ffmpeg.org/

FFmpeg is licensed under GNU LGPL version 3 or later for this build.
See COPYING.LGPLv3.txt and COPYING.GPLv3.txt (incorporated by LGPLv3).
GPL-only and nonfree FFmpeg build variants are not bundled.
This application invokes FFmpeg as a separate process; its DLLs remain
replaceable in this directory. Replacing them does not require rebuilding
the application. Compatibility and user replacement are the user's choice.

Exact binary archive, hashes, versions, source references and build recipe
are recorded in manifest.json. Upstream archive:
https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-09-30-13-08
FFmpeg source:
https://github.com/FFmpeg/FFmpeg/tree/29e619e767
Corresponding build and dependency-source recipes:
https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-09-30-13-08
Rebuild with Docker/bash: ./makeimage.sh win64 lgpl-shared 8.1
then ./build.sh win64 lgpl-shared 8.1.
The scripts.d directory identifies source revisions and source locations
of included dependency libraries. The archive is a retained month-end
release; preserve it and matching source artifacts for published releases.
