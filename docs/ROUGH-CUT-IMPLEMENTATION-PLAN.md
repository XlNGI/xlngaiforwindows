# 粗剪工作台实施计划

2026-10-28，用户确认效果图并授权实施。

## 确认范围

- 素材库与粗剪通过现有工作区同时打开，可调整宽度；粗剪内部不增加重复素材列表。
- 右侧片段属性默认收起，仅点击“属性”展开；选中片段不自动展开。
- 素材库支持“加入粗剪”和“导出到剪辑软件”，继续支持多选与拖拽。
- 整集通过用户明确选择的一组场次组织，不新建分集实体。按集数选择时读取已应用场次创建记录的明确分集标题与真实 ID，合并同集分段保存；命名粗剪序列保存的显式场次分组优先，旧项目可手动设置集数与场次。按场次／镜头位置排序，整场视频优先，没有整场视频时使用单镜视频；缺失素材明确提示。
- 卡片勾选使用细线圆圈，悬停、聚焦、已选中或多选期间显示，触摸设备保持可见。直接拖动缩略图，不单设拖动按钮；视频底部保留播放控件。支持单个／多选视频拖入预览区与时间线，显示插入落点，支持 Escape／失焦取消；应用内指针通道补足 WebView 原生拖放差异。
- 图片与视频画面统一支持 Alt／Ctrl 加左键追加或取消单项、Shift 加左键按当前列表顺序选择连续范围，Alt／Ctrl 加 Shift 追加范围；兼容 Meta。初始选中项和勾选按钮可作为范围起点，连续 Shift 保持起点；组合键选择不触发播放或粗剪导入，视频底部原生控件保留。
- 普通素材库拖拽载荷仍按生成时间排列；粗剪接收时按故事顺序建立快照，用户后续调整不被后台排序覆盖。
- 初期提供单视频轨、同步原声、片段排序、分割、裁切、删除、静音、画面适配、撤销重做、预览与项目本地自动保存。
- 通用剪辑交接使用 Final Cut Pro 7 XML（xmeml）及媒体副本；明确格式，不声称自动操控或兼容所有剪辑软件。保留完整序列 JSON；MP4 由本地 FFmpeg 渲染。
- MP4 导出从点击时显示保存与准备状态，随后显示进度；完成后保留完整文件路径和打开文件夹入口，面板重新挂载保留当前会话的导出结果，启动文件管理器失败时明确显示错误。
- 素材引用固定 ID／内容哈希；素材或源文件变化时提示，不静默替换；导出不改写源文件。
