# 提示词内联素材引用

## 审计

制作面板与 Agent 参数表单共享模型 Schema，但普通 prompt 与 content[].text 分别使用 textarea/input。图片按 images、media 或 content 的实际顺序提交；角色声音在制作面板提交前才加入参数。现有 IR 和参数已经表达真实素材身份，无须新增业务 IR 或数据库结构。

## 实施计划

1. 共用参数引用投影：从实际模型参数获取图片、音频、视频身份和官方引用写法；仅识别明确编号，不根据角色名猜绑定。
2. 共用内联编辑器：正文与缩略图标签混排，支持插入、删除、剪贴、撤销、中文输入和换行。使用 Lexical 处理浏览器编辑和选区，持久化仍为普通提示词字符串。
3. 制作面板、Agent 表单及嵌套 content 文本接入同一组件。素材重排同步重写编号，替换或移除不允许旧引用静默指向其他素材。删除正文标签不删除模型输入素材。审核表单仍直接提交。
4. 聚焦验证身份、编号、草稿恢复和提交一致性，执行全仓质量门禁，并同步 Markdown/DOCX。

## 验证

### 实施结果

- `PromptReferenceEditor.tsx` 使用同一 Lexical 纯文本编辑器显示图片缩略图、音频和视频标签；支持插入、中文输入、换行、剪贴、撤销和键盘边界删除。预览沿用现有图片查看器及项目作用域。
- `prompt-references.ts` 从实际 `images`、`media`、`content` 和视频参数获取引用，复用既有官方编号。素材重排仅按原身份同步重写，替换或移除不会把旧编号转绑到其他素材。未匹配的正文保持文本，不按角色姓名猜绑定。
- 制作面板与 Agent 表单，以及结构化 `content[].text` 使用同一编辑器。参数修改、标签投影和提交使用同一份参数。最终仅传普通提示词和模型原有媒体字段，不保存 HTML 或新增业务 IR。
- 结构化参数可从本地表单记忆恢复，嵌套本地图片字节仍不写入记忆或草稿。保存草稿冻结选中的声音版本和媒体顺序；重开后重复投影相同声音不会重复添加，仍拒绝不同声音快照或手动音频混用。
- Agent 已审核表单继续直接提交，并由原有提交锁防止重复点击；本次没有新增草稿或第二次审核流程。
