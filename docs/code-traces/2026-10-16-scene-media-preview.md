# 场次角色媒体预览

## 实施合同

- 角色关系只使用已批准的角色文档 ID。缺少图片或声音选择表示使用角色默认；显式禁用独立保存，不能被自动补齐。已有明确图片／声音版本保持固定。
- 默认图片取该角色来源关系下最早生成且未删除的图片，后续新增图片不替换它；多图可在本场指定。默认声音使用角色当前样本。生成任务继续冻结实际素材 ID、声音版本和哈希。
- 场次一次批量查询最多 30 个角色及 60 个已绑定素材 ID；已选媒体按 ID 读取，不受素材库分页影响。读取不写回所有场次，不增加轮询。
- 已固定的历史声音仍可试听；新版本显示更新提示，不暗中替换。生成继续执行既有版本校验。
- 异步预览只更新发起它的项目／场次；事件只使相关角色失效，迟到响应不得覆盖新选择。失败显示可重试状态，不作为“无媒体”。
- 图片使用按内容哈希复用的真实缩略图，可见时加载，放大才请求原图；音频使用原生播放器、preload=none。媒体正文不进入 IPC。

## 修复边界

原场次只有明确保存的媒体 ID 才会预览，角色后补资源不会自动解析；已选图片还受全局素材列表首批 60 条限制。新增只读 `scene.media.resolve` 批量查询，使用角色文档 ID 和任务 `sourceDocumentId` 关系，不根据角色名称猜测归属。旧明确引用保持固定；未指定媒体使用角色默认，独立禁用标志表示本场不使用。来源查询通过项目及来源文档表达式索引定位。

图片使用可重建的项目本地内容哈希缓存，最长边 320 像素，合并同内容并发请求并限制两个 FFmpeg 编码任务并行。桌面预览进入可见范围才请求缩略图，放大才请求原图；Tauri 将 `asset.thumbnail` 返回路径加入原生媒体访问范围。音频点击后才进行文件读取与播放校验，正文不经过 IPC。角色图片页复用同一预览组件。

生成时解析实际图片和声音版本，既有生成快照继续冻结实际输入；旧声音版本可试听，提交仍遵守原版本校验。场次读取不批量回写，角色声音变更按项目与角色过滤，生成完成触发当前场次刷新，不增加轮询。迟到响应与已切换的项目／场次隔离。
