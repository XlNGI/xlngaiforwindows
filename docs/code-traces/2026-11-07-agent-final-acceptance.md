本次先冻结该构建执行真实任务，发现并修复以下完成／恢复边界，没有修改 Token 窗口、阈值或生成正文：

| 原因                                                                               | 实现                                                                                                                                                                 |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assertTaskPartialAllowed` 只检查 missingTexts/repairRequired，遗漏 remainingCount | 所有待办共用同一门禁；需要本任务真实 failed Result 中明确 retryable=false 才能以受阻部分结束。仅模型理由、未知错误、成功结果、其他任务失败和可重试参数错误均不能放行 |
| 历史已接受的 partial 回执可能继续影响当前完成判断                                  | 完成求值重新读取当前任务的阻塞 Result；历史审计不改写，但无有效阻塞证据不能跳过待办                                                                                  |
