## 正文中确认的问题

1. **8 个镜头全部遗漏相对秒数动作节拍。** 冻结视频模板明确要求“按本段相对时间从 0 秒写至自然内容结束，每个动作节拍明确起止秒数”，实际正文均为叙事概述，没有相对秒数范围。25 秒、20 秒等数值只在独立 `timing` 字段中。正文也缺少模板要求的“氛围与画质”和明确动态流程组织。结论基于逐镜全文核对，不仅依据标题搜索。
2. **地点参考图混入剧情表演与道具特写。** “发布会后林砚所处的工作空间”写着“侧栏特写仅取主图中真实存在且有剧情依据的手机界面局部”；其他地点稿还包含不利文件、授权书和笔的局部以及人物动作。这违反本次模型已读取的场景资料规范中关于地点参考图不混入手机等剧情道具特写的要求。
3. **定稿仍保留互斥动作与位置。** 镜头 05 的“沈砚舟在她对面或近旁”、镜头 07 的“顾承川的压力从画外或对面传来”、镜头 08 的“笔被放回桌面或停在纸面上方”，都没有确定实际拍摄内容。视频模板已经明确要求定稿不能用互斥备选敷衍具体过程。
4. **发布会的不利文件错绑为三年前的授权书。** 镜头 01、02 的正文写发布会上用于归责林砚的文件，道具绑定却都是“核心项目授权书”。该道具正文明确属于三年前第一次授权事件，源稿没有确认它与发布会的不利文件为同一物件。ID 和类型合法，不能证明语义关系正确。
5. **资料绑定混入“输入图片说明”。** 8 个镜头均用该说明描述角色、地点或道具文档绑定，本次实际没有图片附件。部分正文明确说明“未生成图片”，因此不能据此指控模型虚称看过图片；具体问题是未清楚区分制作资料引用与实际图像输入。
