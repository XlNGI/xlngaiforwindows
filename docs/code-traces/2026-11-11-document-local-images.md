# 角色 场景和道具的本地图片绑定

2026-11-11 用户要求：在角色、场景和道具页面中，添加电脑已有图片并绑定，支持拖动添加。

## 范围与实现

三类资料页面原先通过生成任务快照中的 `sourceDocumentId` 查询图片，缺少本地文件入口。本次复用这条资料图库与制作参考链路，将用户显式导入记录为成功的本地任务及其素材结果。用户随后确认“删除”仅解除当前资料的绑定，保留素材和其他资料的绑定；追加 Schema v78 的资料图片排除记录，不调用付费 Provider。

- `DocumentImageGallery` 提供“添加图片”多选按钮、Windows Tauri 原生文件拖入、目标区域高亮、即时预览和失败重试。资料未保存时提示先保存，只读资料保留预览。
- `document.images.import` 验证当前项目、资料类型、生命周期和可写状态。仅接受角色、场景和道具制作资料，拒绝小说域资料以及发布或审核中的只读资料。
- 从原镜头衔接导入逻辑提取 `LocalMediaImportService`，共用执行限流、文件校验、哈希去重、项目副本、事务保存及失败补偿。旧镜头导入继续通过该服务执行。
- 每批 1–12 张，支持 PNG、JPEG、WebP，单张非空且不超过 20 MiB；同时检查扩展名、文件签名及真实 FFmpeg 解码。无效批次整体失败，不保留部分绑定。
- 相同内容复用有效的项目素材，同一资料重复导入不重复绑定；同一图片可关联多个资料。源文件保持原样，项目重开后仍可读取绑定。
- 成功导入刷新资料图库、素材库和制作来源；沿用既有默认图、人工覆盖与“不使用”设置，不批量改写场次和镜头。
- 文件选择期间切换资料，以及导入期间切换项目或卸载页面，均丢弃迟到的界面结果。项目运行卸载会取消共用导入服务。
- 图片下方的“移除图片”调用 `document.images.unbind`，只为当前资料保存排除记录；图库、候选图和自动默认图统一过滤。重新添加同一图片清除该资料的排除记录。生成任务快照、结果与来源审计不改写，素材文件、素材库、其他资料及场次／镜头已明确保存的引用保留。
- 解除绑定校验项目、活动三类制作资料、非小说域、可写状态及实际图片关系；重复解除幂等。写入失败整体回滚；桌面失败可重试，切目标或卸载后的旧结果不回写新页面。

普通会话附件不会自动导入或绑定；素材与关系仍保存在本地项目文件和 SQLite 中，GitHub 仅用于源代码及评审。

## 聚焦验证

桌面 23 项通过，涵盖文件选择与取消、原生拖入坐标和目标命中、监听释放、重复结果、数量和格式校验、未保存及只读、迟到结果隔离、错误重试和三类页面入口。

## 界面验证

使用隔离的 Vite 夹具加载真实 `CharacterSceneWorkspace` 和项目样式，以内存素材和合成预览替代原生对话框及 Worker。验证添加后自动显示、图片放大，以及三类资料 × 深浅主题 × 320／390／700 px 共 18 组面板布局；添加按钮可见，图片区域及列表均无横向溢出。验证结束后关闭临时浏览器页、停止 Vite 并删除夹具源码。

此验证不等于 Windows 安装包中从资源管理器拖入的实机验收。未修改真实项目数据库，未调用付费模型。
