# 并发 P5d：文件任务与异步导入导出

日期：2026-10-17。保留已有修改，项目 Schema v52→v53，应用 v8 保持。

新增项目本地 file_tasks owner，只覆盖原来没有持久化任务的项目导出、备份和小说导入。`file.task.create/get/list/cancel` 返回稳定任务 ID、进度、修订和终态；操作键/hash 去重，取消意图落盘，输入只保存摘要，终态清除暂存请求。恢复将未结束项标记 interrupted，不自动重放导入或覆盖目的地。原接口适配到同一 owner。

所有重文件任务共用 1/app 文件阶段容量，业务接纳总上限仍为 32/project。项目导出继续 P0 的 SQLite backup、文件流复制/hash 校验及暂存目录发布；流复制和 backup 分页支持取消。备份拒绝覆盖已有目标。小说导入先在事务外按章节验证并预计算切片，阶段间让出事件循环、检查取消；正文和 RAG/检索索引仍在同一提交事务内写入。

Markdown 导出继续原 markdown_export_jobs/items，不另建重复 owner。新增 start/get/list/cancel，原 prepare 兼容为等待完成。冻结版本后异步写文件、实际回读验证、短事务登记验证点，再发布完整目录；无长文件 IO 跨 SQLite 事务。取消只清理本次创建且目录身份仍匹配的暂存/输出，不触及其他任务目录。重启沿用原 manifest/hash 对账，queued 遗留也会明确失败。

Desktop 维护入口接纳后即可离开，任务日志展示独立文件进度与取消；小说导入/导出保留当前页面观察与取消，切换页面不停止任务。

验证：Worker Project/Runtime/Markdown/Novel/File 43 项通过，其中实际 64 MiB 导出期间 health 响应低于 500 ms、B 项目可创建会话、A 导出可取消且无暂存残留，错误 scope 不可读取 A 文件任务。文件池排队取消零导出、幂等复用、失败导入零部分章节/索引、冻结版本导出、非空目标保留和恢复不重放均通过。Desktop 小说/日志/文件列表 34 项及 App 79 项通过。v50→v53 四个迁移故障回滚用例通过；Typecheck 通过。最终全仓/Sidecar/NSIS 门禁在 P6 执行。

真实系统休眠、上一发行版升级及付费 Provider 仍不属于本阶段验证。完整项目导出可失败要求重试，绝不以缺失引用的快照报告成功。
