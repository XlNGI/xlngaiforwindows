## 不变量、状态和所有权

- 导航只读当前项目元数据，正文仍按需，不改变索引、draft/published、附件、权限及项目会话隔离。
- 裸父级 ID 仅在当前可见目录中唯一匹配合法父类型时规范化；未知、跨项目、隐藏归档及错误父类型明确拒绝。存在但没有子项的场次是合法空页。
- 不同筛选目标的空页是不同查询证据；相同筛选、版本及有效结果重复四次仍终止。页大小、detail、临时句柄和空页越界偏移不能伪造进展。
- 查询证据来自工具实际回执，跨历史整理、持久化恢复与 checkpoint 采用同一身份。读取不产生保存状态，保护拒绝仍保留所有已保存内容。
- 镜头修复只替换已核实资料 ID，使用原有项目锁、业务保存与 CAS，不修改正文、时长、顺序或任务状态。
