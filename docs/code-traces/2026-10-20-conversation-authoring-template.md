# 会话编排模板规则同步

日期：2026-10-20。

## 反馈与范围

用户确认将会话要求约束模板与现有镜头编排指导同步。旧模板虽要求沿用已确认资料，但允许“需要变化时写清原因”，且强制每镜填写外观、空项填“无”，未明确禁止根据夜景或全局色调重设计造型。

本次只修改内置可编辑初始文本及需求记录，不改保存、加载、发送组合逻辑或用户项目数据。新会话自动使用更新后的初始文本；已有会话可手动合并条款，或在备份自定义要求后点击“载入分镜制作模板”，该按钮会替换当前编辑内容。“重新加载已保存约束”读取的是用户保存版本，不会升级到新模板。

## 实施清单

- [x] 明确造型来源、换装依据及服装固有色与光照的区别；未知细节省略，未见图片不能声称已看图，锁定项不充当新造型的证据。
- [x] 用屏幕空间细化站位、朝向、路线与遮挡；身体特征落实到可见动作，不从失明推断跛行。
- [x] 动作按相对时间拆分，原文对白归属具体说话者和节拍，区分上一镜已说完与本镜新台词；声音明确节奏和远近。
- [x] 区分初始、过程、结束和关键定格，省略无关可选项，保留有意义的否定；按整场／单镜范围填写，避免带入无关角色和参考。
- [x] 全稿一致性核对覆盖共享场次及每镜各字段；冲突单独说明，保留可编辑稿及用户最终表单修改权。
- [x] 完成现有模板状态、会话面板回归及相关质量检查，记录结果。

本次仅修改初始文本，未重复运行上轮已通过的全仓 1,692 项测试。上述回归验证模板读写与界面行为，不证明真实 LLM 或视频模型的遵循质量；未发起真实生成。
