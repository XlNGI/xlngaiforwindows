## 建议修正的职责边界

角色创建／重设计需要明确区分三件事：

1. 已有明确外观、参考图与用户指定不可擅改。
2. 尚未设计的可视属性，在角色设计任务中可以形成具体、一致的可编辑草案；不得冒充原稿已经确认的事实。
