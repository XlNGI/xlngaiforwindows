# 角色音频图标交互

用户确认角色音频只需一个添加按钮，添加后以音频符号显示并可点击试听。

## 实现

- 角色资料页直接使用紧凑声音样本组件，不再挂载供应商音色配置、制作声音入口与两块说明面板。
- 添加继续经过桌面文件选择、Worker 本地音频导入与角色声音版本保存。当前角色仅绑定当前样本，替换保留既有历史版本语义；不修改 Worker、SQLite 或素材库对象结构。
- 音频以 36 px 图标显示，悬停显示名称／时长，按钮包含可访问名称与播放状态；点击后读取音频，使用 `preload="none"` 的隐藏音频元素播放，再点暂停。
- 播放失败显示提示；只读禁用添加但可试听；角色或项目改变时重新挂载、停止旧音频并丢弃旧导入结果。
- 明确覆盖窄屏隐藏次要按钮的通用样式，保持添加入口可见。

## 验证

- 聚焦组件：22 项通过，覆盖添加、取消选择、替换行版本、真实媒体读取接口触发时机、播放／暂停／结束、失败重试、只读、切换角色及旧异步导入丢弃。
- Edge 隔离夹具：合成 4 秒 WAV 实际解码并推进播放时间，暂停／继续成功，切换角色后旧音频暂停；点击前不调用音频文件读取，点击后只读取一次。
- 深浅主题分别验证 320／390／440 px，共 6 组，无横向溢出；空状态仅一个添加按钮，有音频时增加一个图标，无原生播放器。
- 全仓 `pnpm typecheck` 与 `pnpm build` 通过；生产构建保留既有单包体积提示，变更源码 ESLint 通过。
