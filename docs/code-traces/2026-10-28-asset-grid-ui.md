# 素材网格 UI 修复与验证 2026-10-28

用户指出并排工作区中素材卡片显示异常，要求优化红框区域。本轮沿用方案 4.5 的方形完整预览、按需显示别名／标签及底部日期／大小，不改变已确认的产品规则。

## 问题与修复

使用真实 `AssetLibraryView` 和当前样式，在 838 px 宽素材面板中加载 20 条合成素材，复现隐式网格行被压缩为约 62 px；230 px 的预览区超出卡片后被隐藏，素材只露出横条。

- 网格行按内容确定高度，卡片使用纵向 flex 布局，超出面板的素材通过滚动浏览，不压缩卡片。
- 预览区保持 1:1 并禁止收缩，图片／视频定位在预览框内，以 `contain` 完整显示横图、竖图和方图。图片不裁切，原生视频控件保留。
- 调整卡片圆角、12 px 间距、内边距及悬停阴影；类型标识置于媒体上方，保留原有细线圆形多选图标与柔和选择配色。
- 信息区增加细分隔线，统一日期和大小字号，暗色主题使用可读的次要文字颜色；没有别名或标签时仍不创建对应的信息行。

改动仅在 `apps/desktop/src/styles.css`，不涉及 Worker、项目 SQLite、素材文件或交互处理函数。保留任务开始时已有的其他未提交修改。

## 验证

- Chromium 使用真实组件和隔离 RPC／合成媒体，在约 840、1280、600、374 px 面板下检查布局，包含浅色与深色主题、20 条与 60 条素材、长别名、标签和横／竖／方图。所有预览保持方形，媒体与信息均在卡片边界内，无页面或网格横向溢出；多素材通过网格或窄面板内容区滚动。
- 在同一 838 px 面板中，修复后的预览为 237×237 px，无别名／标签的卡片为 277 px 高，20 条素材的网格滚动高度约 3063 px，不再压缩到可视高度。
- 实际鼠标与键盘验证 Alt 追加、Shift 范围选择、原生视频播放，以及缩略图直接拖动的指针移动／落下流程。拖动接收端是明确的合成验收夹具，没有写入真实项目，也不将其作为 Tauri 到真实粗剪序列的端到端验收。

- 素材库既有组件测试 16 项通过。桌面生产构建（含 TypeScript 检查）、变更 CSS 的 Prettier 和 `git diff --check` 通过，构建仍有既有的大包提示。此次为局部样式修复，未新增实现镜像测试、重跑全仓测试或生成安装程序。

本轮修复落实已有显示要求，没有更改确认规则，因此不改动 DOCX；不改变原计划的 DOCX 逐页及 Windows 发布验收待办。

## 素材视频播放条去除黑色渐变

用户进一步指出视频卡片底部播放条的深色背景。仅调整缩略图内原生控件的背景为透明，露出卡片的浅色／深色底色；浅色主题将控件转为深色并保留细微浅色投影，保证按钮和进度条可辨认。继续使用原生播放器，不修改选择、拖动、播放或媒体源逻辑；规则排除全屏视频，右侧详情播放器保持原样。

Chromium 隔离夹具在 1024、840、374 px 面板下分别验证浅色与深色主题，六组截图已检查，黑色渐变已去除，无页面横向溢出或页面异常；真实鼠标操作播放／暂停及进度条跳转均通过。夹具补齐本地合成视频的 HTTP Range 响应，避免把验收媒体服务不支持跳转误判为产品问题。证据为本聊天 `implementation-qa/asset-grid/controls-report.json`、`controls-final-*.png` 和 `controls-page-*.png`。

桌面生产构建（含类型检查）、变更 CSS 和记录文档的 Prettier、`git diff --check` 通过。此次仅调整控件样式，未新增或重跑组件／全仓测试，也未进行 Windows Tauri 原生截图验收；已保留原有发布验收待办。没有改变确认的产品规则，无需修改 DOCX。

## 后续调整：原始比例完整预览

用户进一步要求优先保证素材文件完整预览，并尽量减少空白。将固定方形预览改为按媒体固有比例布局，图片和视频使用自然高度及 `contain`，不裁切、不拉伸；缩略图继续由内容决定卡片高度，网格按内容排列。视频控件在悬停或键盘聚焦时显示，触屏设备保持可用。元数据就绪而浏览器尚未解码视频画面时，播放器在前端轻量定位到首帧附近以触发画面解码。

这轮改动限定在桌面素材库组件、样式和组件测试，没有新增 Worker 服务／接口、数据库字段或素材处理业务。曾尝试的 Worker 缩略图方案已撤回，Worker 测试中的误留空行也已清理；粗剪导出等既有 Worker 改动属于此前已授权的粗剪实现，保留不动。

素材库组件 16 项测试、桌面生产构建、相关 ESLint、Prettier 及 `git diff --check` 通过。隔离浏览器检查 1280 与 390 像素布局、横／方／竖比例、控件悬停／聚焦状态和横向溢出；此次不替代 Windows Tauri 发布验收。
