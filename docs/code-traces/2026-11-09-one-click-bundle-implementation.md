# 剧本整包提示词：实施与离线闭环记录

日期：2026-11-09。对应[实施计划](../ONE-CLICK-PRODUCTION-BUNDLE-IMPLEMENTATION-PLAN.md)。最终命令、计数及构建指纹见[机器证据](./2026-11-09-one-click-bundle-implementation-verification.json)。

本轮接入镜头、场景、道具、角色、音色样本提示词与显式绑定的整包流程。源码、组件、真实临时 SQLite 和打包 Worker 的离线机制分别验证。没有调用真实供应商、创建媒体任务或替换用户运行实例，不能将以下结果当作真实模型内容验收。

## 最终行为

1. 同一一键入口冻结源 ID／版本、完整要求、点击时刻和预算，显式选择工作流 v2、Skill revision 8；历史任务保持 legacy／revision 7。
2. 小包联合候选，大包按稳定 key 串行分包。全文、版本、hash、读取范围与候选都在现有 Result Store，不提前写业务表或检索索引。
3. 程序核对清单、来源／目标 CAS、项目／类型、数字时长、显式引用和完整阅读；后续模型响应才能集中提交语义审查。审查仍由模型执行，程序不承诺模型不会漏判。
4. 局部修复仅撤销相应依赖。候选／修复／同类错误／轮次／时间／Token 有固定上限，轮询和参数重试不冒充业务进展。
5. 同一本地短事务预分配真实 ID，保存文档、同版本 IR、场镜、绑定、索引、变化序号及唯一回执。事务内无模型、网络、媒体或用户等待。
6. 独立读取实际正文、IR、版本、位置和关系，全量比较后记录核对。完成时还会重新检查；候选就绪、可提交审查和业务已保存分别显示。
7. 音色正文保存描述，版本 IR 保存独立试音文本；角色默认音色与可见／画外／旁白台词用真实 ID 绑定。文字音色不伪造音频或供应商音色。
8. Desktop 可编辑及跳转全部对象，显示分类数量与点击后耗时。准备时间计入总耗时；无点击时间的历史任务只显示任务耗时。

保留已有场镜位置，新对象按候选顺序追加；候选要求与实际顺序不兼容时提交前报 `BUNDLE_ORDER_CONFLICT`。独立读回包含位置。新增可选 `timing.locked` 强类型标记，新版整包及 Agent 时长工具不得解除保护。

## 已验证的故障窗口

- 不完整分包、UTF-8／单项／整包边界、分页缺口、旧 hash、未读完正文、当轮生成即审查均无法取得有效完成依据。
- 错类型／缺失引用、未冻结复用版本、被改动的源／复用资料、目标 CAS／发布保护、同名不同对象、无道具无声音及画外说话者分别覆盖。
- 文档版本、镜头、角色音色关系、项目检索块、写入回执、执行提交故障均回滚本次业务写入，候选保留可重试。
- 提交前取消不落业务实体；提交后取消保留已保存事实。响应丢失／重开后重复提交恢复原回执和 ID。
- 168 对象测试分页遍历全部真实映射，单次回执小于 64 KiB；读回可检测正文台词和场镜位置的独立持久化变化。
- 两种 Provider 协议经实际打包 Worker、统一 Runtime、工具授权、候选分包、后续模拟审查、事务提交、重放与读回，自然进入 completed；随后 SQLite 只读重开全量比较。
- UI 覆盖独立试音编辑、dirty／CAS、默认音色选择、画外／旁白台词与跳转、只读、数量／耗时反馈；绑定读取期间禁止提交视频表单。

## 验证中发现并修复

首次全仓测试发现旧道具“只改正文时清除旧结构 IR”的合同被泛化保留逻辑改变。已收窄到独立试音字段及角色默认音色关系；原视觉资料合同恢复，原断言保留。

新增边界测试发现时长锁定检查缺少可持久化的 Schema 字段。已补齐布尔合同、序列化及 Agent 保护，非法标记拒绝保存。发布反例改用领域 selfPublish，遵循真实发布触发器。

最终全仓复验暴露声音草稿恢复时的异步窗口：绑定尚在读取，提交按钮已可用。补齐读取／错误门禁，并增加可控延迟读取反例；没有通过放宽原断言绕过问题。

## 耗时与未完成项

点击时刻由 Desktop 入口提供并冻结，任务时长与点击后时长分列，本地操作以单调时钟记录；Provider 请求沿用发出、首包、完成和 Token 账本。跨进程墙钟不当作精确子阶段测量。

离线脚本输出的约数秒是固定模拟回答下的机制执行时间，不是 LLM 阅读、生成或语义审查耗时，不能用于提速百分比、一般耗时或 SLA。

P7 仍受原供应商 `403 insufficient_user_quota` 阻塞。尚未使用原完整约束及三份源文档完成真实模型复验，未核对真实提示词质量、真实 UI 首次显示或一般耗时分布。旧真实失败记录保留。本轮没有安装、替换或重启用户应用，也没有恢复已暂停监控。
