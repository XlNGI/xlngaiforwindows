# 用户模板驱动提示词生成修复验收

实施：2026-11-16；收尾：2026-11-17。R0–R5 已实现并验证，R6 的质量门禁已通过，真实内容与普通返修收尾仍有下述限制；未覆盖当前运行实例。

## 结论与根因

原沈砚舟提示词缺少外观，主要是后台制作 Skill 的“未知外观省略”和冻结通用模板中的“未知信息不补造”共同限制了设计，并非已证实数据库删掉了外观文字。原失败正文从模型已解析工具参数到保存正文一致。

另一个独立缺陷是 Native 普通聊天流用相等／前缀推测重复片段，吞掉重复中文、数字、独立空白和换行。本轮按两种协议的标准增量合同修复；工具参数仍保持精确拼接。

## 已实施机制

- 用户本轮请求、冻结通用模板和当前用途专项是创作要求来源；后台 Skill revision 34 仅保留执行、ID、权限、绑定、版本、CAS、幂等、事务及保存合同。
- 六用途统一：通用、角色图片、地点图片、道具图片、镜头静态图、视频。剧情场次属于视频用途，地点资料属于场景图片用途。
- 整包在同一 Runtime、Task State、Result Store 和候选集合内按用途串行生成。阶段版本与候选 revision 独立；stageKey 重放不回滚当前阶段；重启保留冻结模板与用途。
- 最终请求明确发送一份通用和当前专项的完整正文；旧阶段模板、工具说明副本与评论在当前请求中不继续生效，原记录保存在本地。依赖资料按需读取，不自动注入未读取的项目正文。
- TXT／MD／Markdown 文件以 UTF-8 解码导入当前用途草稿，可预览、编辑、撤回和清空。BOM 消费后其余文本保留；错误编码明确拒绝；1 MiB 文件限制明确报错，不截尾。异步导入不会覆盖切换后的用途／会话或新输入。
- JSON v2 内部边界保留包含内部标记的用户原文、模板、CRLF 和空值。聊天界面显示原请求，不展示内部 JSON。
- 镜头静态正文、用途、意图和独立视觉绑定与视频分开；在同一最终事务保存。回执明确给出静态图数量和读取定位。需要静态图时，在视频阶段暂存，最终静态图提交时才封包。
- Pi 累计文本按显式 responseId 更新；不同响应的相同文字不会被按内容删掉。

用户既存模板和历史草稿没有静默重写；空模板不补回默认创作规则。旧任务保留其冻结执行合同。没有增加运行时语义评分、审查模型或语义提交门禁，也没有生成媒体。

## 真实模型内容核对

通过 agent.run → conversation.runtime.start → 打包 Worker → Native Windows 凭据边界 → 实际供应商 HTTP。供应商配置为 ergou-gpt-chat、Chat Completions、gpt-5.6-terra；这里只确认配置名称，没有供应商底层模型身份证明。没有模拟真实输出，也没有物理点击 UI。

第一组采用同一《逆光成锋》大纲版本 db287455-5627-47db-80bf-e0ecfa22eacf、不同冻结模板和新会话。会话共享隔离项目，早期生成草稿后续可被按需检索；不将它描述为完全相互隔离的内容实验。

整包内容样本使用另一份独立六秒静默走廊剧本及五专项自定义模板：一角色、一地点、一场次、一镜头、独立静态构图；无音色、无道具、无媒体。

1. 首次 282.97 秒、23 次请求：保存了角色／地点／场次／视频，提前封包使静态图缺失。结构读回通过，但内容验收失败；模型最终如实报告缺项。随后补强非最终提交省略 complete、静态图最后封包的执行说明。
2. 第二次 329.72 秒：独立静态图与视频均保存，静态图为开始时站定的单幅构图，视频包含三个时间段。但视频把角色资料的海军蓝西装写成深灰，跨对象固有色不一致，内容验收仍有不足。随后补充在缺少依赖全文时按候选 key 读取，并增加静态项回执定位，避免重复确认。
3. 最终包复测 260.29 秒自然结束：角色服装与静态图连续，五类交付完整、一次事务保存并读回；视频具备三个确定时间段，静态图只写开始时站定构图。仍发现视频把地点资料的深灰蓝地毯写成浅灰地面，地点图和静态图保留地毯。记录为内容偏差，随后使用现有 Agent 修订路径，仅返修场次／镜头环境措辞；不把结构校验通过写成内容全通过。
4. 定向返修在原 ID／CAS 上修正场次与镜头：深灰蓝地毯、中灰护墙板、冷白线性 LED、磨砂玻璃办公门和远端半透明玻璃门写入视频。逐字段比较确认仅两个 prompt、row_version 与 updated_at 改变，全部源稿／角色／地点文档与独立静态图原样保留，绑定、时长、标题、ID 和对象数量不变；已解析 Assistant 参数、执行参数和保存正文一致。但普通任务随后反复校正场次交付计数、无法自然完成，421.23 秒观测、33 次请求后停止验证宿主以避免继续付费循环。该项记录为“内容返修已保存，任务自然收尾未通过”，没有改数据库状态伪造成功，也未为此扩展修改既有普通任务计数服务。
