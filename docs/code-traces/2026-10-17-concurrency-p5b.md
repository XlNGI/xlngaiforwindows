# 并发 P5b：图片与视频阶段容量

日期：2026-10-17。保留已有修改，项目 Schema v52、应用 v8 不变。

图片批准提交接入与视频共用的持久化调度 owner/dispatch；原 generation job 保持唯一业务状态。图片与视频共享提交容量，实际执行前重新校验确认、冻结参数和来源。Provider 响应已知后释放提交名额，本地处理继续拥有原 dispatch；未知提交不进入重发路径。关闭新调度的兼容入口仍有共享提交限额。

图片完成按项目代次/任务及输出 hash 合并重复回调，拒绝同一活动 owner 的不同输出；每批最多两项下载，并与所有项目的视频下载共用 2/app 额度。全部图片验收后才原子入库；失败、取消或旧运行回调保持原补偿协议。取消可中止目标下载并释放容量，不影响另一个项目；原生结果暂存只在各读取者结束后清理。

项目快照纳入图片任务和修订变化，后台图片完成会刷新素材。制作面板批准后可继续提交其他任务，显示按任务区分的后台图片与独立取消；旧 finally 不清除新任务的准备/确认状态。素材库继续只展示成功且已落盘的图片/视频，不展示排队、失败和取消任务；别名、标签、手动组及拖拽快照语义均未改变。

验证：Image/Media 64 项通过（含共享 submit、过期确认零调用、取消排队零调用、跨项目下载实测峰值 2、多图失败零部分入库、取消释放额度、重复结果去重）；Video/Runtime/项目集成 39 项通过。制作面板 42 项通过，包含同面板两次提交、定向取消与另一任务独立落盘；App 79 项和场次面板 11 项在本阶段聚焦回归通过。全仓 Typecheck 通过，最终构建、测试、Rust 与打包在 P6 复验。

没有真实付费调用，也没有把模拟结果作为 Provider 成功率或正文/画面质量验收。新阶段不增加自动付费重试、图像远端轮询或模型替换。
