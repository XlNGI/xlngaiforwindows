# 提示词统一生成：审计、实施与验证

日期：2026-11-17。对应[实施计划](../PROMPT-GENERATION-UNIFICATION-PLAN.md)。本轮依次完成审计、计划、源码实施和离线验证；保留工作区已有更改，没有安装或替换运行实例。

## 审计与实现

| 边界 | 原行为 | 新行为 |
| --- | --- | --- |
| 一键入口 | 把源定位交给普通 Agent，模型读取 Skill、正文并切换用途 | Worker 自动冻结完整来源、显式绑定依赖和适用模板；首次请求直接创作 |
| 通用 Agent | 多个通用工具可以独立处理生成操作 | 通过 `prompt.generation.request` 结构化声明真实源版本和用途，进入同一个专用生成器；普通查询和已有对象 CAS 编辑保持各自职责 |
| 创作阶段 | 模型管理 begin、用途切换、候选分批、revision 和封包 | 只暴露 `prompt.generation.submit`，完整正文与关系 IR 同轮返回，Worker 按用途/字节分包 |
| 保存与完成 | 既有候选、校验、原子保存/回读 | 复用同一套服务，整包结构错误回滚；保存成功后 Pi 本地结束，恢复已有回执时也无需模型收尾 |
| 表单 | 本地编译已存在 | 保留本地 schema 映射、人工值与冻结提交；新增测试明确禁止该流程发起模型请求 |

主要实现：`prompt-generation-state.ts` 冻结输入并沿显式绑定 IR 取依赖；`prompt-generation-schema.ts` 定义请求/结果合同；`prompt-generation-service.ts` 系统编排分包并复用 `ProductionBundleService`；`AgentContextManager` 投影专用请求；`PiConversationRuntime` 在已保存并回读后本地结束。Native 的 Responses 与 Chat Completions 分别编码强制输出工具选择，Worker 和宿主两端都检查其确实在授权列表中。

新普通 Agent 不再获得旧 `production.bundle` 控制工具；新一键/专用阶段只有结果提交工具。历史任务通过冻结快照继续原合同；没有改写旧任务。通用任务未声明提示词生成之前，系统不按关键词强制路由。

失败保护包括：项目/会话隔离、源版本冻结、用途、唯一 localKey、显式引用类型、CAS、单事务、回读、无媒体操作；准备连续失败和专用创作分别限制 3 次。超出输入容量明确失败，不能裁剪正文或隐藏补写。

离线闭环中每种协议保存 2 角色、1 地点、1 道具、2 音色、1 剧情场次及 1 镜头；输出来自受控本地响应。两协议均在首次请求后修改模板并强杀 Worker，恢复仍使用原冻结输入；修复一次错误引用后自然结束，没有再发模型总结请求。

验证中发现并修复：普通 ContextManager 没有 Agent 任务行时不得误进专用阶段；资料单用途需要允许没有场次/镜头的清单；独立镜头静态图必须在其视频候选后于本地分包；归档后的失败候选与错误要恢复全文；失败选源不能被认定为只读完成。已有一项界面测试要求提示文本含旧 Skill 标识，已更新为检查一次生成行为和无需读 Skill。

## 验收边界

内容抽查未发现角色服装颜色、地面材质与走廊空间在静态参考及视频镜头中的明确冲突；新增设计均有草案措辞，静默源稿未保存声音资料或独立道具。个别角色五官仍只用“清晰、沉静”等概括，未达到更具体特征的高质量标准，故标记为部分内容通过。首次诊断发现供给静态图的内容超出一键冻结用途时模型可能无视边界，以及模型可能省略 bindings 或创建新的静态图镜头 key；实现已增加本请求动态 kind 枚举、固定 request hash、显式 bindings 指令与具体错误，回归测试及最终四份均通过。通用 Agent 样本的有限修复体现结构护栏工作，不表示每个首轮创作都必然成功。
