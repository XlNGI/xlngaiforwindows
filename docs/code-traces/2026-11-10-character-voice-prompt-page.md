# 角色页内编辑音色提示词

用户确认音色提示词应位于对应角色提示词页面。本次仅调整 Desktop 编辑体验，复用原有文档与版本保存接口。

- 角色页新增“音色提示词”区，按角色的明确 `voiceDocumentId` 读取音色描述与试音文本，直接编辑并通过页面“保存草稿”保存。
- 仅修改音色时只写音色文档，角色视觉正文及版本不产生额外修改；角色绑定有修改时仍由原文档保存入口提交。
- 音色保存携带自身行版本，保留同版本绑定。已发布、审核中、只读项目不可编辑；加载失败可重试。角色或项目切换后，迟到的读取不能显示在新对象上。
- 音色修改纳入页面 dirty 与关闭保护。保存冲突保留输入；未保存音色时禁用音色切换并拦截角色切换／新建／恢复版本，关闭页面可放弃修改。
- 音色描述不拼入角色生图提示词；不创建音频、占位文档、供应商任务或数据库迁移。

- 三个聚焦测试文件：31 项通过，覆盖编辑保存、重开、CAS 冲突、关闭保护、只读、加载重试和跨角色／项目迟到响应。
- `pnpm --filter @ai-video/desktop build`：TypeScript 与 Vite 生产构建通过。

验证范围是源码、组件和前端构建；未替换用户安装实例。声音生成与整包真实供应商验收不属于本次页面调整。
