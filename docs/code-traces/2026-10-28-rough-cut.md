# 粗剪工作台实现与验证 2026-10-28

## 实现结果

进入“粗剪工作台”会同时停靠素材库和编辑面板，素材库默认在左侧。编辑页不重复展示素材列表，属性初始收起，选中片段不会展开属性。

素材库支持把选择的视频加入粗剪或直接导出 XML 媒体包。整集选材使用显式场次集合，按现有场次、镜头位置选择视频；普通素材库拖拽的生成时间排序规则保持原样。新增素材进入粗剪时按故事顺序排列，用户调整后的顺序不被重新排序。

序列支持非破坏裁切、分割、排序、原声静音、画面适配、版本替换、撤销重做及连续预览。序列存储在项目 SQLite，使用版本 CAS。自动保存串行执行；面板停靠引起的重新挂载先等待在途保存，失败编辑继续保留于当前项目会话。

导出使用本地媒体副本并校验内容哈希，避免把选择后已变化的源文件静默导出。XML 包含 xmeml、媒体、序列 JSON 和导入说明。MP4 通过随包 LGPL FFmpeg 的受支持 H.264 编码器和 AAC 输出，统一为 30fps；静音或无音频视频补入静音轨。导出可取消，失败时清理临时目录。

## 按集导入与拖放补正

用户指出“整集选材”并没有按集数导入，卡片选择按钮难以识别，素材也无法拖入粗剪。本轮修正以下路径：

- `roughCut.episodes` 从本项目已应用的场次创建记录读取明确分集标题与真实场次 ID，合并同一集的分段保存，并按场次位置排列。用户命名的粗剪序列保存场次分组，优先于生成记录；不新增 episodes 表，不按素材时间猜测场次归属。无分集关联的旧项目通过“手动设置集数与场次”建立可复用分组。
- 按集导入可新建序列保留当前剪辑，重复导入跳过相同素材；调整场次会覆盖分组而保留当前片段。异常显示在导入弹窗内，避免错误被遮在弹窗之后。
- `assets/asset-pointer-drag.ts` 复用素材快照协议，通过同文档指针通道向粗剪派发探测、移动、落下及取消。独立视频拖动手柄支持单选／多选，预览与时间线均可接收；时间线支持前后插入，落点反馈明确，Escape／失焦取消。原生素材组和制作面板拖放协议保持有效。
- 选择按钮常显、28 像素、蓝底白勾，提供可访问的 pressed 状态；拖动后保留多选，选择或拖入不会展开属性。

## 视频组合键选择修复

视频卡片原先在 video 的 click 中无条件阻止冒泡，Shift 范围选择没有收到视频画面的点击；选择函数也只识别 Ctrl／Meta，没有识别用户要求的 Alt。本轮在卡片捕获阶段处理视频画面点击，底部原生播放控件仍保持独立交互。组合键指针按下不启动拖动，画面选择阻止默认播放。

图片与视频统一使用 Alt／Ctrl／Meta 切换单项、Shift 选择当前可见列表内的连续范围；追加修饰键与 Shift 组合时合并原选择。范围起点可回退到默认选中项，点击圆形勾选更新起点，连续 Shift 保持起点以便扩大或缩小范围。
