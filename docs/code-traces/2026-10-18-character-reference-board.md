# 角色设定板用于视频参考

用户确认视频角色参考应采用示例图一、三、四这种包含多个视角与局部细节的完整设定板；示例图二的单幅剧情坐姿画面属于本次角色素材交付失败。最低要求为同一人物正面、侧面、背面全身三视图，加上面部、发型、服装、配饰与道具局部细节。示例图一、三、四仍须逐张核对三视图是否齐全，多个设定板也须采用同一画风。

更新内置会话模板与制作实施计划，明确设定板作为视频角色外观参考，保留完整信息；将其与镜头首帧分开，提示模型不要把标题、边框、多面板和多视角重复人物生成到视频画面中。实际参数用途取决于所选模型能力。

本次变更限于提示词约定和产品要求记录。模板继续由用户编辑，新会话使用更新后的初始文本；已有会话仅在用户主动载入时采用，不改写项目数据库或已选素材。设定板自动生成、图像内容验收和所有生产入口的约束执行需要后续工程实现。
