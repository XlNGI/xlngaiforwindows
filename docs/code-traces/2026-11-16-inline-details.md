# 素材与任务详情原位展开

2026-11-16，用户确认素材详情在所选素材整行下方占满当前面板宽度，任务详情紧随当前条目展开，并采用极简样式。

- 素材库默认收起详情，普通点击、再次点击和 Esc 控制单项展开；批量选中与详情独立。来源深链可以明确展开目标素材。按实际网格列数定位跨列详情，调整面板宽度时保持详情节点和正在编辑的别名。
- 素材详情以细分隔线、完整预览、别名、标签和常用操作组成，文件信息默认折叠。详情与网格共用滚动区域，图片放大、视频原生控件、只读、回收站、来源定位和拖拽继续可用。
- 任务详情移入对应条目下面，所有宽度均保留列表；再次点击、“收起”和 Esc 折叠。收起及切换条目按当前条目修正滚动位置，关闭后恢复键盘焦点。请求身份检查继续隔离迟到结果。
