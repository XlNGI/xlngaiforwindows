# 生成表单以用户最终填写内容为准

日期：2026-10-20。

## 问题与确认要求

用户将优化后的镜头提示词粘贴到生成表单后，不同视频模型都被制作说明拦截，报错包括前置状态缺证据和外观锁定值变化。当前镜头只有江晚和老瞎子，不能为了消除旧说明中的沈孤鸿状态报错而补造人物或剧情。

用户确认：自动编译用于预填建议；填入表单后可以自由修改，最终提示词、时长和素材选择以表单为准。制作说明过期、连续性缺证据和外观差异仅作提醒。模型参数无效、实际输入素材不可用、目标不属于当前项目及付费确认无效仍应拒绝。

本要求更新 `2026-10-17-scene-production.md` 中针对手工表单的“来源修改后不能提交旧表单”规则。直接采用结构化指令的 Agent 路径继续检查来源版本和制作依赖。

## 实现

- `ProductionSource` 区分结构化指令来源与 `mode: form` 的最终表单来源。表单仍记录目标和可用的指令版本信息，作为来源记录；该字段不传给模型。
- Desktop 不在提交前重新编译、用旧制作问题拒绝提交或覆盖手工修改。说明更新只提醒，用户仍可主动重新填入建议。
- 用户编辑提示词或结构化内容后，提交时不重新追加旧角色图片标签；显式选择的声音输入继续按实际选择处理。
- Worker 在准备任务和付费确认时识别最终表单来源，确认目标属于当前项目，不把旧剧情状态、旧估时、旧必需素材重新施加给表单。
- 实际参数仍经过适配器校验，实际输入仍经过素材归属、文件及内容检查，最终参数和来源保存在任务快照中；原付费确认和禁止自动重提机制保留。
- 未标记为最终表单的既有任务和 Agent 请求保持原来源校验，兼容旧任务。

## 验证

- Hook：连续性/外观提醒、说明更新或编译不可用时，用户最终表单仍可提交；不在提交时重新编译。
- 制作表单：含沈孤鸿警告及图片标签的旧说明不会向用户改写的江晚/老瞎子提示词追加沈孤鸿；提交仍等待付费批准。
- Worker：旧剧情时长及必需参考图不会阻断有效手工表单；无效模型时长、目标不匹配和不存在的目标仍拒绝。
- 付费确认：确认期间项目说明变化不会改写或阻断冻结的最终表单，模拟 Provider 只收到用户最终参数。
- 实际素材：最终表单中不存在的本地图片仍在准备任务前拒绝，未创建生成任务。

所有生成链路验证使用临时项目及模拟 Provider，不调用真实付费生成，不修改用户项目数据。
