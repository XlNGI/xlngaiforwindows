# 镜头编排沿用已确认人物造型

日期：2026-10-20。

## 反馈与原因

用户测试的断剑石对峙镜头，把江晚写成“玄色劲装、高马尾、右臂旧布带”，并在画面定格、人物描述、起始状态及锁定外观中反复使用。文字已经提出黑衣要求，仅附上原角色参考图不能消除这组冲突。

渲染器按结构化字段输出，不会自行从调色板选择衣服颜色。问题出在编排内容缺少明确的外观来源边界：上一轮指导要求核对身体特征，未充分强调服装固有色、发型、配饰不可根据情绪或夜景自行重设计；旧 `novel.episode.submit_structure` 入口还未附上共用编排指导。本次没有读取用户实际项目资料，不能断言该次模型调用究竟读取了哪份设定，或将“玄色劲装”归因于某个确定的检索结果。

## 实施

- [x] 先明确外观依据：实际读取的人物设定、所选角色参考图、用户修正和原文明示的本场变化。未知细节省略；未看到图片不能声称已看图或“按设定板”描述。

- [x] 共用规则覆盖分阶段、直接提交、已有对象更新及旧分集提交四个入口；Native/Pi 继续使用同一工具目录。Schema 就近说明人物外观、服装、发型和画面定格的填写边界。

这是编排指导与 Schema 说明的修正，不是对任意服装描述的确定性语义识别，也不能保证 LLM 或视频模型每次都遵循。没有新增提交拦截、外观自动比对、额外模型调用或全文注入；用户最终表单仍可自由编辑。没有改变素材选择、索引或本地存储，也未修改用户已有项目文本。
