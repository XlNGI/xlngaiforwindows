# 所有草稿目录支持批量删除

用户确认：所有草稿目录都需要支持批量选择和删除。

覆盖范围更正：本记录初版遗漏了独立存储的场次／镜头目录，其批量选择、归档、可恢复删除与恢复已在[场次与镜头生命周期补修](./2026-11-05-scene-shot-lifecycle.md)补齐；完整覆盖情况以两份记录共同为准。

原先仅小说章节有用于制作与导出的选择框，普通项目文档和小说资料没有共享的批量操作入口；后端还将小说资料与章节一起排除在普通文档归档、恢复流程之外。

- [x] 共享选择和删除：剧本目录的大纲、计划、约束，角色与场景目录的角色、场景、道具，以及小说目录的章节、大纲和资料，均提供勾选、全选、取消全选和“删除所选”。筛选后全选只增加当前可见草稿，已有选择保留；切换目录清空选择。
- [x] 确认和失败处理：确认弹窗列出文档及数量，提示当前文档未保存更改的处理方式；逐项携带版本检查，部分失败时保留失败项选择并报告结果。项目或会话切换后停止剩余批次，不将旧项目结果写入新项目界面。
- [x] 恢复和编辑器状态：普通文档、小说资料使用 `document.archive/unarchive`；小说章节继续使用专用章节生命周期接口。成功后移除当前目录条目，清理对应编辑器及普通文档的独立窗口，并提供归档／已删除列表的恢复入口；刷新失败保留已成功归档的本地列表状态。
- [x] 后端边界：允许小说资料归档和恢复，保留其正文、版本和领域绑定；章节继续禁止走普通文档归档接口。发布只读、项目权限、审计及行版本检查保持有效。
- [x] 定向验证：Desktop 共享批量操作、小说工作区与文档工作区 Hook 共 44 项通过；App 目录集成 1 项通过；Worker 文档和小说服务共 29 项通过，包含真实 SQLite 中小说大纲的归档、过期版本拒绝和恢复验证。
- [x] 页面验证：从实际 App 提取目录 JSX，使用实际共享批量操作 Hook、角色场景组件与样式，在隔离内存数据页面验证 320 / 390 / 900px 面板、深浅主题、全选、取消、确认和成功状态。目录和工具区无横向溢出，确认标题列表可滚动。截图保存在本地忽略目录 `apps/desktop/.m2-ui-draft-batch/proof.jpg`。
- [x] 质量检查：全仓 TypeScript 类型检查、生产构建、本次变更源码与测试的 ESLint／Prettier、`git diff --check` 通过。

全仓回归结果：Desktop 795 项通过、1 项失败；失败为 App 任务日志页面仍期望“项目执行记录”而实际标题为“任务日志”的既有断言，与本次批量操作无关。单独继续执行的 Worker 1283 项、Persistence 88 项、Generation Adapters 80 项均通过；Contracts 47 项、Context 8 项、LLM 32 项通过。
