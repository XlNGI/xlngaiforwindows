# Agent 用量、缓存与上下文预算实施计划

日期：2026-10-21。用户已确认直接实施，沿用当前分支，不合并。

## 不变量

- 普通会话只自动获得有界目录，正文、记忆、约束仍按需读取；草稿标记、附件不入库、本地 SQLite、原授权/CAS/调用额度保持不变。
- 用量按真实模型请求去重，调度等待和工具执行不是模型请求。失败/取消保留已报告用量；缺失值为未知，历史记录不补造。
- 本地费用为定价快照估算，供应商报告金额单列，不混币种、不把推理 Token 重复相加。
- 保留工具懒加载；规则与工具不能根据用户文字关键词自动路由。只有已授权 Schema 可以加载。
- 用户消息与补充完整保留。仅在预算阈值整理可定位、可重读的旧工具正文，保留版本、来源、状态、CAS、实际产物与未完成工作。不能安全整理时在发送前明确结束，已保存进度保留。
- 不请求真实 Provider，不重发历史任务，不修改用户运行时 SQLite，不重启应用。

- 消费补充只返回已持久化且尚未消费的输入，不改写 `context/prompt`。Pi 同批按原顺序追加全部补充；相同文字的不同输入仍独立保留。输入配额、幂等操作键和任务分支隔离保持原校验。
