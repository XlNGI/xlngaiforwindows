# 场次角色与音频统一绑定

## 确认范围

- 场次继续绑定一个可复用制作场景，新增独立的出场角色列表；角色使用文档 ID，与是否已有图片无关。
- 每位出场角色可选择一张参考图及一个明确的声音样本版本。声音样本属于角色，场次保存所选版本；替换声音不自动改写场次或历史任务。
- 完整对白音频可单独绑定场次；台词、采用配音和时间位置沿用现有配音仓储。声音参考与完整对白驱动分别按模型合同提交。
- 自动绑定由 LLM 理解场次完整视频提示词，并返回真实场景、出场角色文档 ID 的结构化结果；系统仅校验和执行，不使用姓名包含、关键词或正则推断业务关系。角色与场景遵循同一语义责任边界，用户仍可明确手动调整。此前基于占位符名称查找素材的实现不满足本规则，需按下方补充清单修正。
- 图片、声音按稳定顺序编排，提示词明确角色与图片、音频编号。模型不支持的组合、数量或失效版本在提交前提示，不静默省略。
- 旧图片绑定仅在已有有效角色文档 ID 时迁移；既有台词角色加入出场列表，不按人名猜测。历史任务保持快照。
- 数据保存在当前项目 SQLite；音频继续使用独立仓储，不改变图片／视频素材库入库、素材组、拖拽或回收站合同。不扩展普通会话正文注入。
