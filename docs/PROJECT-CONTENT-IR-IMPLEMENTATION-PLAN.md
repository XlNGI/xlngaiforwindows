## 用户确认的目标

角色、场景、道具、音色样本、场次和镜头的提示词都是可编辑的普通文本，不再分别建立内容 IR 或制作 IR。只定义一套绑定关系 IR，使用明确的项目内 ID 表达关联。此次重建直接删除不再需要的业务、字段、转换、校验和测试，不保留旧运行时分支或兼容包装。

文本由 Agent 理解和编写；应用不从姓名、标题或正文猜测关联，不强制创作字段、动作节拍或结构化对白模板。音色试音文本是普通文本字段。生成需要的时长是独立数值参数，不属于绑定 IR。

## 新的数据边界

- 文档版本保存普通正文、可选试音文本和同版本绑定；场次／镜头保存普通提示词、独立时长和绑定。
- 唯一 PromptBindingIR 只包含格式版本及角色、场景、道具、音色的 ID 关系，不含提示词、创作扩展数据、时长或对白正文。
- 所有读写、候选提交、表单和生成链路消费相同合同；移除内容 IR／制作 IR 及候选到这两类 IR 的转换。
- 绑定验证负责项目、实体类型、活动状态和明确空列表；正文修改保留有效绑定。CAS、授权、事务和付费确认继续由基础设施执行。
- SQLite 一次性迁移保存已有正文、时长、试音文本和明确绑定，再删除旧 IR 列。迁移只在项目正常升级时运行，不修改本次会话之外的用户项目。
- 草稿／正式版本同库，正文按需检索；附件不自动入索引，运行数据及索引仍在本地项目 SQLite。
