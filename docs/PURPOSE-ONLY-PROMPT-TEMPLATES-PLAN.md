## 确认的行为

- 编辑器仅保留角色图片、场景图片、道具图片、镜头静态图、镜头视频五类模板。系统提供各类可编辑初始模板，用户可导入、修改或清空。
- 新任务不注入通用模板；普通讨论不注入专项模板。执行权限、真实 ID、版本、事务等工具合同继续属于系统职责。
- 发送前保存专项编辑并冻结版本。执行中修改只影响下一任务，原任务恢复沿用原快照；空模板不补回默认。
- 根据源稿生成新制作提示词，使用统一生成入口按对象类型组装各自模板。直接编辑制作文档时，Worker 检查真实输出类型与已发送的冻结专项模板一致，不能用通用用途跳过。小说人物设定和普通文档保留原流程。
- 模板校验检查用途、版本和全文 hash，不把五视图、固定标题或固定措辞写死。正文仍为普通可编辑字符串；结构和保存成功不等于语义全部合格。
- 历史数据库共享文本保留用于历史查看/恢复，新编辑器不展示或修改它，新任务不应用它；不做破坏性迁移。
- 内部辅助计划/音色产物已有的 `general` 用途身份为历史/业务兼容保留，不代表存在通用模板；新任务的模板工具不提供该选择。
