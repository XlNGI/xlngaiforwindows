# Agent 业务执行可靠性改造

日期：2026-10-20。基线：main `98ad96d`；分支：`codex/agent-business-reliability`。按 P0 → P1 → P2 → P3 → P4 → P5 实施。

## 目标与边界

模型负责理解用户、选择目标和创作内容；Worker 负责授权、版本、请求预算、幂等、候选整体校验、事务和任务终态。保留本地 SQLite 模块化单体，不增加云端数据存储、自动付费调用、正文自动注入或新的草稿审批。

复用已有 generation/attempt、制作清单及不可变指令历史。正常会话由模型判断意图，不恢复关键词路由。失败/取消后保留原对象、真实 ID、人工修改和已保存产物；已有分段可通过原任务查询续作，不自动重放失败任务或计费操作。

## 不变量、所有权和状态

- 每个真实模型请求在发送前计入同一 generation 的 24 次预算，包含初次、工具加载、修复；正常终止响应不再被当作下一轮。32 次业务调用、检索独立预算和原授权边界继续生效。
- 制作命令属于当前项目/会话/任务；Worker 可根据操作内容和任务生成稳定执行键。旧客户端显式键继续严格校验，同键不同内容必须拒绝。
- 先检查全部 CAS 和结构，再保存候选整体状态。同内容、同来源的操作返回 unchanged，不改对象行版本、指令 revision 或检索索引；仍保存有界命令审计。来源变化不能当作 no-op。
- 批量操作先处理引用文档，再保存场镜，最后基于整批最终来源建立不可变指令快照；任何结构、权限、CAS 或落盘失败整体回滚。
- 连续性可比较事实使用真实对象引用、稳定属性和状态值；key/value 保留可读说明。旧自由文本不得被当作语义等价判定依据；缺失证据和自由文本差异标记待核实，明确结构化矛盾及锁定状态变化仍拦截制作。
- 图校验与顺序编译共用事实处理规则；共享初始事实和锁定事实参与镜头校验。未知事实不得驱使模型虚构前置剧情；缺少依据时报告待确认。
- 已保存、待处理、制作就绪为不同事实。草稿可带 readiness 问题保存；生成前仍检查所有问题和来源令牌。
- Agent 读取默认提供结构或一份指令，不重复展开正文；长内容显式分页，包含继续读取信息。过期指令可检查原有时长和内容，但必须显式标记 stale，不能作为当前有效生成来源。
- 读取复用按项目会话、目标及依赖版本失效，不能只看场次 rowVersion；引用、父子、前置、默认值、素材/连续性变化均不得返回旧结果。缓存有界，不存凭据和授权句柄；工具授权与预算每次仍由 Worker 验证。

状态沿用：generation prepared → streaming → complete/failed/cancelled；命令在一个 SQLite 事务内 accepted → applied（changed/unchanged），出错整体回滚。预算不足在请求发送前结束任务，日志准确保留已保存进度，不将局部产物与整个任务终态混为一谈。

## 故障矩阵

| 场景 | 行为 |
|---|---|
| 第 24 次模型响应为 stop | 正常完成，不产生第 25 次请求 |
| 第 24 次仍要求继续 | 下次发送前失败；保留所有已保存对象 |
| 参数修复、工具加载、补充消息 | 使用同一个请求预算，不能多计或漏计 |
| 同键重试／换键提交相同内容 | 前者返回原结果，后者返回 unchanged；不增加业务版本 |
| 同键不同内容／旧 CAS | 拒绝；不能用 no-op 绕过并发检查 |
| 引用文档更新但指令文字相同 | 重新核验并保存明确的新来源版本，不误判 unchanged |
| 一批关联镜头更新／中途异常 | 按最终候选校验，成功原子保存，异常整批回滚 |
| 前置事实缺失／旧自由文本差异 | 单独返回待核实问题；不冒充确定矛盾，也不自动清除问题 |
| 真实状态矛盾／锁定状态改变 | 明确问题；允许保留草稿，生成继续拒绝 |
| 指令过期但有时长 | 返回已有时长和 stale，不伪报缺少时长 |
| 长正文／同内容跨工具返回 | 使用精简视图和有界分页，不能静默丢失唯一内容 |
| 引用、子镜头、前置或素材变化 | 旧读取版本失效；不能按相同参数复用旧内容 |
| 切换项目、关闭、取消、重启 | 原身份围栏保持；不跨项目缓存，不自动调用 Provider；沿用持久化任务终态恢复 |
