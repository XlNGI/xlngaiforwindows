# 用户错误指引

日期：2026-08-02

## 项目无法新建或打开

### `rootPath must be a string`

项目目录为空或没有作为文本传给 Worker。请在“项目绝对目录”中填写完整 Windows 路径，例如 `D:\Projects\my-drama`，再点击“新建”“打开”或“创建示例项目”。

### 项目以只读模式打开

同一项目已有另一个可写实例，或项目 Schema 高于当前应用支持版本。关闭占用该项目的其他应用实例后重新打开；如果 Schema 版本更高，请升级应用，不要用旧版本强制写入。

### `project.sqlite was not found`

选择的目录不是项目根目录。项目根目录应直接包含 `project.sqlite`，不要选择 `assets`、`backups` 等子目录。

## Provider 请求失败

### HTTP 401/403

先核对设置中的服务区域：国内站密钥应选择国内站，国际站密钥应选择国际站。密钥只填写原始值，不要带 `Bearer` 或 `Token` 前缀。确认模型和 API 版本来自当前适配器目录后重新提交。

### `fetch failed` 或 `ECONNRESET`

这是连接或下载链路失败，不代表任务一定未生成。保留任务并重试查询；如果关闭代理后恢复，说明代理无法访问结果存储域名。代理规则需要同时允许 Provider API 域名和结果下载域名。

### 视频长时间处于轮询

任务中心会根据持久化截止时间自动终止，不会永久轮询。网络恢复后可继续任务；应用重启不会重新提交计费任务。Provider 已成功但本地仍在下载时，状态会显示为下载中。

## 本地文件和空间

### 磁盘空间不足

生成结果写入前会保留最少 16 MiB 的安全余量。请在“项目维护”中检查并清理媒体缓存，或释放项目磁盘空间后重试。缓存清理不会删除素材库、备份、导出文件或项目数据库。

### 结果没有出现在素材库

未勾选自动保存时，生成预览不会自动登记为素材。使用结果区的“保存到素材库”，并确认选择了角色、场景、首帧、尾帧或普通生成素材类型。

## 启动和安装

### 开发模式提示端口 1420 被占用

已有 Vite/Tauri 开发实例正在运行。关闭旧应用和对应终端后再执行 `pnpm dev:desktop`。不要同时启动多个开发桌面实例。

### 安装后 Worker 无法启动

发布包已经携带独立 Worker，不要求安装 Node.js。若仍失败，打开一个项目后进入“项目维护”，导出脱敏诊断包，并将整个诊断目录提供给维护人员。

## 导出诊断信息

打开右上角“项目维护”，选择“导出诊断包”。默认保存到当前项目的 `exports` 目录，也可以填写其他绝对目录。导出后点击“打开位置”。

诊断包不包含 API 密钥、Authorization、签名 URL、请求正文、创作正文、SQLite 数据库副本或项目绝对路径。发送前仍建议打开 `report.json` 和 `manifest.json` 做一次人工确认。
