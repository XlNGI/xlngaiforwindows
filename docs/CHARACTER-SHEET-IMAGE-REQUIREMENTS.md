# 角色图片默认设定板要求

日期：2026-10-22。依据：用户提供的角色设定板示例及“角色的图片应该包含这些细节”的要求。

## 交付内容

角色图片默认制作一张完整设定板，各分区展示同一人物，沿用项目已确认的角色与美术设定。

| 分区 | 内容 |
| --- | --- |
| 主立绘与信息 | 大幅完整全身立绘；已有名称、身份、备注、性格关键词和能力说明的简短标签。 |
| 全身五视图 | 正面、前 3/4 面、侧面、背面、后 3/4 面；统一比例与基线，头顶至鞋底不裁切。 |
| 头部六角度 | 正面、3/4 面、侧面、俯视、仰视、动态角度；面容、发型和辨识特征一致。 |
| 服装与配饰拆解 | 实际穿戴的衣物、鞋履、配饰及连接结构；已有常备武器／标志道具的结构与佩戴关系。 |
| 材质与色彩板 | 实际存在的材质纹理、光泽与粗糙度；主色、辅色、点缀色与对应部位。 |
| 表情与氛围 | 符合角色的表情差分与氛围头像；仅在已有能力设定时展示对应效果。 |

示例用于信息覆盖与版式参考，不把示例人物的身份、白发、黑衣、武器或能力复制到其他角色。未知身份、性格、材质与能力不补造；临时剧情道具继续独立制作。明确要求头像、单幅立绘、仅三视图或其他版式时，按该次要求调整。
