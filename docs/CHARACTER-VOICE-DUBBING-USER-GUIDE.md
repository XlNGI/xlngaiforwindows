# 固定角色声音与场次配音

首版支持固定角色声音、场次台词、WAV／MP3 导入、配音试听和采用、口型处理及完整场次成片。音频和制作记录保存在当前项目，最后的视频保存为新素材，源视频保留。

## 1. 配置角色声音

在设置的供应商连接中添加“MiniMax 配音”，在 Windows 桌面应用里保存密钥并测试连接。启用 Speech 2.8 HD 或 Turbo。

打开“角色与场景”，选择已经保存的角色，在“角色声音”中选择连接、模型和音色 ID，设置基础语速及音高后保存。音色 ID 应来自自己的供应商声音目录；可使用预设音色或账号已有的克隆音色。首版不创建克隆音色。

保存声音生成新版本。角色改名不改变声音绑定，后续修改声音也不覆盖历史配音。角色归档后不能继续生成新配音，已保存音频仍可试听。旁白可在场次配音面板中建立声音配置。

## 2. 准备和确认配音

打开“场次与镜头”，选择场次，点击“打开配音”。添加台词并选择角色或旁白，设置开始时间、情绪及句后停顿。

可以导入本地 WAV／MP3，或在确认费用后点击“生成配音”。单条台词最多 4,000 字符，导入文件最大 20 MiB，单条配音最长 60 秒。输入较长对白时请明确拆分，系统不会自行截断。

试听每个版本后点击“采用配音”。需要不同表演时点击“重新生成新版本”；成功配音会保留。修改文字、说话者或情绪后，需要重新选择匹配的版本。修改起点等画面编排可以继续使用原配音。

## 3. 本地合成或处理口型

选择当前项目中的源视频。

- 选择“直接配音合成”可在本地完成配音，适合旁白、背影或不需要口型的片段；不调用付费生成接口。
- 选择“先处理口型，再合成”，需添加并测试 Sync 官方连接。只给有可见说话者的台词勾选口型处理，并填写人物说明和画面中的相对位置。位置横纵坐标在 0～1 之间，例如画面中心为 0.5、0.5。

配音时间不能重叠，完整对白必须能放进视频。视频不足时应调整位置、拆分或制作更长画面。系统不自动变速、循环或截掉尾字。

成片会移除源视频原音轨，包括背景音乐和环境声，并按已确认的配音合成。提交前确认这一选择，源视频本身不会被覆盖。自动分离对白及背景声不属于首版功能。

## 4. 费用与任务恢复

远程配音和口型处理由用户手动提交。费用未知时仅允许确认单个口型片段；处理多个片段需填写币种、每秒报价及本次预算。报价是本地估算，实际扣费以供应商为准。

提交结果未知时先核对供应商任务，系统不自动再次提交。已保存任务 ID 的口型任务可恢复查询，成功配音和口型片段可以复用。失败的本地合成可重试；重新发生费用需要另行明确确认。

关闭配音面板不会停止任务。切换或关闭项目会停止本次本地制作，远端已发生费用不保证退还。任务日志显示“配音制作”及步骤状态；制作期间不能清理缓存。

## 5. 成片与项目保存

完成后对比源视频与成片，试听并点击“采用成片”。新视频同时出现在素材库。查看素材来源可以返回场次配音入口。

音频由独立配音仓储管理，不加入图片／视频素材库。被配音版本或任务引用的音频不能直接删除；正在制作的视频不能删除。历史视频引用遵循素材库的二次确认规则，彻底删除仍受历史引用保护。

迁移项目请使用完整项目导出，包含数据库和媒体文件。SQLite 单库备份不包含音频或视频。项目完整性检查会报告配音文件、口型片段及关联视频缺失或内容变化。

## 6. 当前验证边界

本地媒体流程、原生接口协议夹具和界面已经验证。用户已选择将真实付费样片放到后续验收；因此目前不能把工程检查通过视为中文音色、侧脸或遮挡口型质量已通过实测。

FFmpeg 版本、许可证与重建方式见 [共享媒体运行时](./FFMPEG-RUNTIME.md)。阶段状态见 [实施计划](./CHARACTER-VOICE-DUBBING-IMPLEMENTATION-PLAN.md)。

## 7. 角色声音样本直接生成视频

在 Windows 桌面应用的“设置 → 供应商连接”添加“万相视频（百炼官方）”、“Seedance 视频（火山方舟官方）”或“MiniMax 视频（官方）”，保存各自 API Key 并测试。万相需填写北京地域的百炼业务空间 ID，密钥、模型权限与业务空间应匹配；另外两家使用固定中国官方地址。连接通过后启用要使用的视频模型。

当前内置万相 3.0／Prime、万相 2.7 图生视频、Seedance 2.0／2.5、MiniMax H3／H3 Max。账号需开通所选模型；连接测试通过不代表所有模型均已获授权。

在“角色与场景”选择已经保存的角色，找到“视频声音样本”，导入清晰单人的 WAV／MP3 并试听。替换样本会保存新声音版本，角色改名不丢失绑定。此样本可由三家支持声音参考的视频模型读取，不依赖 MiniMax TTS 的音色 ID。

打开场次或镜头的制作面板，选择官方连接、视频模型和参考模式，添加角色参考图与需要生成的台词，勾选“角色声音参考”中的角色后提交。面板按所选角色顺序添加声音参考和提示词，生成前会显示费用确认。多角色时请在提示词中明确画面人物、角色名称和各自台词；严格首尾帧模式与声音参考存在模型互斥要求，界面会拒绝无效组合。

场次页面的“出场角色与声音”可直接添加本场角色，为每位角色选择参考图和声音样本版本；没有图片时也能先绑定角色。选择后点击“保存提示词”保存本场绑定，再点击“生成场次视频”。制作页从独立的出场角色关系预选声音，不再依赖角色是否有图片；提交时按实际图片顺序和所选声音顺序补充角色编号说明。

助手生成场次时，会理解完整视频提示词，返回对应场景和全部出场角色的真实 ID；系统校验后生成待审核方案。批准后，提示词、场景与角色关系一起保存，即使角色还没有图片或声音也能关联。姓名、称谓和“他”等指代由 LLM 结合项目资料判断，系统不按文字匹配角色。

已有场次可点击“让助手关联角色与场景”。修改完整视频提示词后点击“保存提示词”或“生成场次视频”，也会先交给助手提出关联方案；批准后再制作视频。有同名、指代不明或缺少资料时，助手反馈需要澄清的内容，不建立猜测关系。需要配置可用的 LLM 连接，使用当前会话的模型。

新关联角色会选用该角色已有参考图和当前声音样本版本；保留角色已有的人工选图、声音版本及手动清空结果。镜头场景图沿用场次确认的场景 ID，不再解析提示词占位符来选择图片。有本场台词的角色须先调整或移除对应台词，才能解除角色绑定。历史项目不会因升级自动改写角色关系，可按需交给助手处理。

角色声音样本更新后，本场保留已选版本并提示重新选择；不会自动换成新声音。历史视频任务保留提交时的绑定和媒体快照。完整对白可以在场次页面导入或从已有音频选择，保存后由万相 2.7 等完整对白驱动路径预填；声音参考模型遇到完整对白绑定会提示调整模型或绑定，避免静默漏传音频。

建议先用 3～5 秒干净单人录音验证样片。实际允许的格式、数量、单段及合计时长按所选模型检查；Seedance 2.0 的声音参考需搭配图片或视频。Seedance 本地图片和音频可直接使用，参考视频应提供公网 URL 或官方素材 ID。

万相 2.7 面板显示“完整对白驱动”，须导入要在成片中使用的完整对白录音；这条路径不能把音色样本改读成新台词。对白超出画面时长会被拦截，须明确拆分或加长视频。

确认后才会把样本发给所选供应商。后台完成查询、下载和新视频入库，已保存任务 ID 可在重开项目后恢复查询；结果未知时不会自动重复提交。取消停止本地处理，已经发送到供应商的任务和费用不保证撤销。

声音参考可提高音色连贯性，实际结果受供应商模型影响，不能保证每次完全一致。需要严格复用同一音频时，可继续使用前述固定角色配音、采用音频和口型／本地合成流程。本轮尚未消费额度验证三家真实样片。
