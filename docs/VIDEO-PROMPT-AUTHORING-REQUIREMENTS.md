# 视频生成提示词正文规范

日期：2026-10-22。依据：用户提供的参考图说明、武侠雨夜连续动作视频示例，以及“视频生成的提示词应该是这样的”的要求。

## 默认交付

采用示例的正文结构与细节密度，写成可直接用于生成的连续视听描述；具体剧情、人物、时长、节奏和声音取自本次请求及已确认的项目资料。用户明确要求其他格式时按该次要求调整。

| 顺序 | 正文内容 |
| --- | --- |
| 输入图片说明 | 根据实际输入数量和顺序逐图交代可见内容、对应主体、需要保持的特征及用途；区分外观／风格参考与首帧、末帧、中段瞬间。没有图片时省略。 |
| 视频目标 | 本段叙事目的、人物意图、冲突、情绪变化，以及开场、过程和结束状态。 |
| 基础设定 | 实际出镜主体、必要的已确认外观与材质、身体特征、道具、站位和初始状态；对白、旁白、环境声、动作音效及配乐安排。 |
| 氛围与画质 | 时间、地点、天气、空间关系、光线、材质反光；景别、机位、构图、焦点、景深和运镜起止。 |
| 动态流程 | 由 LLM 根据动作、对白、停顿、镜头和节奏自主设计从 0 秒至本段结束的连续时段；动作发起者、对象、方向、力度、反应、重心与道具变化、跟拍和声音时点。 |
| 负面约束 | 本段适用的身份、造型、肢体、画风、人物、道具、字幕、水印、声音等禁止项，与正面描述保持一致。 |

制作正文统一使用 `ProductionAuthoringIR.prompt`，不再使用旧 `promptScope` / `sharedPrompt` 合同。整场优先原样使用场次完整正文一次；没有场次 IR 时按顺序连接镜头 IR 正文。独立单镜或分段只消费当前镜头范围的完整正文，所需背景由模型写入各自 prompt，并使用本段相对时间；系统不从开放 data 中提取共享正文。默认由 LLM 根据动作复杂度、对白长度、表演停顿、镜头运动和叙事节奏自主设计分段及总时长；用户明确给出的时长、已有稿件锁定的时长和所选模型的硬限制优先。`timing.estimatedDurationSeconds` 与正文时长、生成表单对应；超出模型能力时沿用自然动作节点分段与适配说明，不通过删剧情或改写旧正文凑时长。

## 参考图及连续性

- 参考图中的瞬间可以位于剧情中段，不能一律当作第一帧。图片实际传入由所选模型支持的参数决定，文字说明不能改变首帧接口的含义。
- 图号与本次实际输入顺序对应；不凭空添加图片或模型专用占位符，不以提示词中出现“图1”声称已经绑定。没有实际看图时不声称识别到五官或材质。
- 面部清晰只约束脸部可见的镜头。纯背影、脸部不可见或完全遮挡转场有自己的可见范围；不同时保留“全程眼睛可见”与“结尾完全遮挡”的冲突。
- 已脱落的斗笠等物件不再写作持续穿戴状态；明确出招方式，不用“手臂或兵刃”等互斥备选代替定稿，不凭空新增武器。
- 采用示例的写法，不把其中的角色、服装、武侠、雨夜、5 秒、高速开场或无配乐写成所有视频的固定内容。
