# 场景参考图片要求与实施记录

日期：2026-11-02。用户更新决定：单个场景默认只生成一张复合场景图，主图为全景，次图为关键特写；取代 2026-10-29 关于按需生成多张独立场景图的要求。

## 已确认要求

- 每个场景默认只生成一张复合参考图：主图占主要面积并呈现空间全景，次图将关键局部特写拼接在边缘或侧栏，不拆成多张独立图片或等大的视图格。
- 特写只展示全景中真实存在且有辨识或制作价值的细节；保持场景布局、门窗、通道、物件位置与数量、材质固有色、天气、时段及光源方向一致，不镜像空间或编造未确认的内容。
- 单个场景一次只准备一个提示词并调用一次 `media.image.prepare`，默认 `n=1`；只有用户明确要求同版式的多个随机变体时才增加 `n`。
- 特写数量按有价值的关键细节决定，不为凑数增加；整体主次明确、风格和透视一致，不添加标题、说明文字或装饰边框，除非用户明确要求。
- 图片生成成功不代表场景布局与特写细节的一致性验收通过。
