# 素材库优化方案

> **Agent execution source.** 本文件与同目录 DOCX 方案对应；确认规则变化时必须同步更新两个版本。

> 面向生成图片与视频的项目级资产中心

> **版本：**v1.0　 **状态：**已确认
> **负责人：**产品 / 设计 / 研发　 **适用范围：**unicomp · 项目素材库

> **方案结论** 素材库只管理成功生成且可复用的图片和视频；以别名、项目共享标签和动态素材组完成查找与复用，并通过拖拽把素材快照送入具体生产环境。任务过程与失败记录继续由任务日志负责。

## 1. 背景与定位

当前工作台已经具备图片、视频生成结果落盘、素材列表、预览、打开位置、重命名与删除等基础能力，但素材仍以文件路径和类型为主要识别信息，缺少面向内容复用的组织方式。随着同一项目中的角色、场景和镜头素材持续增加，用户需要从“生成结果列表”升级到“可查找、可组合、可直接投入生产的资产中心”。

> **产品定位** 项目级的生成素材资产中心：让用户清楚地查看素材、按自己的方式区分素材，并以最短路径将单个素材或一组素材投入后续生产。

## 2. 目标与设计原则

| 目标   | 产品表现                                                 | 判断标准                             |
| ------ | -------------------------------------------------------- | ------------------------------------ |
| 看得清 | 图片和视频统一浏览，快速预览并显示别名、标签、时间与来源 | 无需打开文件目录即可判断素材是否可用 |
| 找得到 | 搜索同时匹配别名、文件名和标签名，并支持类型、素材组与时间筛选 | 用户能够用自己的命名和分类快速定位   |
| 用得快 | 支持单个、多选和素材组拖拽到生产区域                     | 拖入后可调整用途和顺序，无需复制文件 |
| 可维护 | 标签项目共享、素材组动态更新、删除进入回收站             | 组织规则稳定，误删可恢复             |

- 素材库与任务日志分离：素材库不展示处理中、失败或取消的任务。
- 别名与文件名分离：别名用于用户识别和搜索，不修改磁盘文件路径。
- 轻量组织优先：标签只描述素材；素材组保存标签组合条件，不建立复杂目录树。
- 引用而非复制：拖入生产环境只传递素材引用，原文件保持单份。
- 动态筛选、静态使用：素材组在拖拽前动态更新；拖入后形成当次引用快照，避免生产内容被后续标签变化影响。

## 3. 已确认的产品规则

| 决策项       | 确认规则                                                         |
| ------------ | ---------------------------------------------------------------- |
| 入库范围     | 仅成功生成并已完成本地落盘的图片或视频自动进入素材库。           |
| 素材粒度     | 一次生成多个结果时，每个结果均为独立素材。                       |
| 素材命名     | 仅提供别名，不增加备注字段；未设置时显示可读的默认名称。         |
| 标签作用域   | 标签属于项目，项目内成员均可查看、创建和使用。                   |
| 标签管理权限 | 标签创建者与项目管理员可重命名或删除标签。                       |
| 素材组       | 素材组由多个标签组成，匹配必须同时包含全部标签的素材。           |
| 动态规则     | 素材标签变化后，素材组结果自动加入或移出。                       |
| 拖拽顺序     | 按创建时间从早到晚排列；进入生产环境后可继续调整。               |
| 来源关系     | 任务日志可定位素材，素材详情可返回来源任务；不额外展示使用次数。 |
| 删除规则     | 先进入回收站；存在引用时二次确认，彻底删除作为独立操作。         |

## 4. 信息架构与页面结构

素材库作为独立工作区进入，不与生成任务状态混排。用户点击一级菜单“素材库”后直接进入唯一的素材库页面，默认展示全部未删除素材。页面以高密度浏览和重复操作为主，采用顶部搜索与筛选工具栏、中央素材网格、右侧详情面板的单页面结构；素材库内部不再增加第二层侧边栏或独立导航页。

| 区域       | 主要内容                                       | 核心动作                               |
| ---------- | ---------------------------------------------- | -------------------------------------- |
| 顶部工具栏 | 别名/文件名/标签名搜索、图片/视频类型、时间、素材组、排序 | 清空筛选、管理素材组、多选、批量打标签 |
| 中央网格   | 固定尺寸缩略图、别名、标签、创建时间           | 选择、预览、拖拽、批量操作             |
| 右侧详情   | 大图或视频预览、别名、标签、文件信息、来源任务 | 改别名、改标签、打开位置、进入来源任务 |

页面筛选结构：

```text
素材库：搜索（别名 / 文件名 / 标签名） + [全部素材 | 图片 | 视频] + 素材组 + 时间 + 排序
```

筛选与查询规则：

- 默认展示项目内所有未删除的图片和视频；选择“图片”或“视频”时，同一网格仅展示对应类型，并可继续叠加素材组、时间与关键字条件。
- 顶部不提供单独的“标签”筛选控件；搜索框同时匹配素材别名、物理文件名和标签名称。标签仍用于素材详情编辑、批量打标签和素材组条件，标签管理通过详情区域的独立入口完成。
- “素材组”是保存筛选条件的菜单，同时提供创建、编辑和删除；选择素材组后，同一网格展示其动态命中结果，素材组仍可直接拖拽。
- 回收站通过页面工具栏入口切换删除状态，但仍使用同一页面结构和筛选控件，不建立素材库内部侧边栏。
- 图片在卡片与详情中按完整画面显示，不裁切主体；视频在卡片和详情中提供页内播放、暂停、进度与音量控制。

## 5. 核心对象

| 对象     | 定义                                   | 关键属性                                           |
| -------- | -------------------------------------- | -------------------------------------------------- |
| 素材     | 成功生成并在项目中可用的单个图片或视频 | ID、类型、别名、路径、创建时间、来源任务、删除状态 |
| 标签     | 用户创建的项目级描述词                 | 名称、创建者、创建时间、关联素材                   |
| 素材组   | 保存的一组标签 AND 条件                | 名称、标签集合、创建者、更新时间                   |
| 拖拽快照 | 拖拽开始时解析出的有序素材引用         | 项目 ID、素材 ID 列表、顺序、快照时间              |

> **术语边界** 标签回答“这是什么”；素材组回答“我要复用哪一批”。素材组不是父标签，也不会修改标签层级。

## 6. 核心用户流程

### 6.1 自动入库与整理

1. 生成任务成功，结果完成本地落盘并通过完整性校验。
1. 系统为每个结果建立独立素材记录，并保留来源任务关联。
1. 素材立即出现在“全部素材”和对应图片或视频视图中。
1. 用户按需设置别名，并给单个或多个素材添加项目标签。

### 6.2 查找与复用

1. 用户通过别名、物理文件名或标签名称关键字，以及类型、素材组和时间范围缩小结果。
1. 选择素材组时，只返回同时拥有该组全部条件标签的素材。
1. 用户可创建由多个标签组成的素材组，之后直接打开或拖拽。
1. 素材组结果随标签变化自动更新。

### 6.3 拖入生产环境

1. 用户拖拽单个素材、多选素材或素材组。
1. 系统在拖拽开始时解析可用素材，并按创建时间从早到晚排序。
1. 生产目标校验项目、素材类型与数量约束，再接受引用快照。
1. 目标区域依据自身语义分配用途；例如首尾帧区域接收两张图片，用户可交换顺序。
1. 拖入后即为生产草稿的一部分，后续标签变化不自动增减已拖入素材。

## 7. 关键交互规范

| 场景       | 交互规则                                           | 反馈                           |
| ---------- | -------------------------------------------------- | ------------------------------ |
| 设置别名   | 详情面板或卡片菜单内编辑；去除首尾空格；允许同名   | 保存后立即更新列表与搜索索引   |
| 批量打标签 | 多选后添加或移除标签，不覆盖未选择的其他标签       | 显示成功数量和失败项           |
| 创建素材组 | 输入名称并选择至少一个标签；组合固定使用 AND       | 即时预览命中数量               |
| 拖拽素材组 | 拖拽时解析当前动态结果；已删除或缺失文件的素材排除 | 拖拽浮层显示可投入数量         |
| 跨项目拖拽 | 第一版拒绝跨项目引用                               | 明确提示先导入或复制到当前项目 |
| 删除素材   | 移动到回收站；存在引用时二次确认                   | 可撤销或从回收站恢复           |

## 8. 状态与异常处理

- 空库：提示先完成一次图片或视频生成，不展示任务状态。
- 无搜索结果：保留筛选条件，提供清空筛选入口。
- 文件缺失：卡片标记“文件不可用”，禁止拖拽，并提供打开项目完整性检查。
- 标签已删除：素材解除关联；使用该标签的素材组提示条件失效并要求修复。
- 素材组无结果：允许保留素材组，但拖拽禁用并显示当前命中 0 项。
- 只读项目：允许查看、搜索和预览；禁用别名、标签、素材组、删除与拖拽写入生产草稿。

## 9. 权限与协作边界

| 操作                 | 项目成员       | 标签创建者           | 项目管理员 |
| -------------------- | -------------- | -------------------- | ---------- |
| 查看、搜索、使用标签 | 允许           | 允许                 | 允许       |
| 创建标签和素材组     | 可写项目中允许 | 允许                 | 允许       |
| 修改素材别名和标签   | 可写项目中允许 | 允许                 | 允许       |
| 重命名或删除标签     | 不允许         | 允许自己创建的标签   | 允许       |
| 彻底删除素材         | 不允许         | 不因标签身份获得权限 | 允许       |

> **当前架构说明** 现有 Windows 版本是本地单用户项目，尚无成员身份系统。第一版按“当前本地用户拥有可写权限”执行；上述成员权限作为未来协作层的产品合同预留。GitHub仅用于代码协作，不作为素材库的运行时同步或权限系统。

## 11. 验收标准

- 素材库中不存在处理中、失败、超时或取消的任务记录。
- 图片和视频成功落盘后自动出现，每个生成结果均可独立选择。
- 修改别名后，可立即通过新别名搜索到素材；文件名不发生变化。
- 输入素材的物理文件名或任一标签名称时，可搜索到对应素材；顶部不出现独立标签筛选控件。
- 选择素材组时，只返回同时拥有该组全部条件标签的素材。
- 新素材满足素材组条件后自动出现；移除任一条件标签后自动退出。
- 素材组拖入时按创建时间从早到晚排列，进入目标区域后可以重新排序。
- 拖入后标签变化不会改变生产草稿中的引用快照。
- 任务日志能够定位对应素材，素材详情能够打开来源任务。
- 删除进入回收站且可恢复；彻底删除需单独确认。
- 同一素材用于多个生产位置时不创建文件副本。

## 12. 成功指标

| 指标       | 定义                                         | 建议观察方式               |
| ---------- | -------------------------------------------- | -------------------------- |
| 查找成功率 | 用户发起搜索或筛选后完成预览、拖拽或打开来源 | 本地匿名事件或可选诊断统计 |
| 查找耗时   | 进入素材库至首次有效使用的时间               | 中位数与 P90               |
| 复用率     | 被拖入生产环境的素材占成功入库素材比例       | 按项目和素材类型统计       |
| 整理覆盖率 | 具有别名或至少一个标签的素材比例             | 按项目展示，不做强制 KPI   |
| 误删恢复率 | 回收站恢复次数占删除次数比例                 | 用于判断删除提示是否充分   |

## 13. 方案冻结项

> **无待决策阻塞项** 本方案所需的产品规则已确认。实施中允许调整组件拆分和数据库迁移批次，但不得改变入库范围、别名语义、标签 AND 规则、素材组动态更新、拖拽快照和回收站边界。
