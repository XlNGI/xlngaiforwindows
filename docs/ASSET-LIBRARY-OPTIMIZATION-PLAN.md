# 素材库优化方案

> **Agent execution source.** 本文件与同目录 DOCX 方案对应；确认规则变化时必须同步更新两个版本。

> 面向生成图片与视频的项目级资产中心

> **版本：**v1.2　 **状态：**已确认
> **负责人：**产品 / 设计 / 研发　 **适用范围：**unicomp · 项目素材库

> **方案结论** 素材库只管理成功生成且可复用的图片和视频；以别名、项目共享标签和手动素材组完成查找与复用，并通过拖拽把素材快照送入具体生产环境。任务过程与失败记录继续由任务日志负责。

## 1. 背景与定位

当前工作台已经具备图片、视频生成结果落盘、素材列表、预览、打开位置、重命名与删除等基础能力，但素材仍以文件路径和类型为主要识别信息，缺少面向内容复用的组织方式。随着同一项目中的角色、场景和镜头素材持续增加，用户需要从“生成结果列表”升级到“可查找、可组合、可直接投入生产的资产中心”。

> **产品定位** 项目级的生成素材资产中心：让用户清楚地查看素材、按自己的方式区分素材，并以最短路径将单个素材或一组素材投入后续生产。

## 2. 目标与设计原则

| 目标   | 产品表现                                                 | 判断标准                             |
| ------ | -------------------------------------------------------- | ------------------------------------ |
| 看得清 | 图片和视频统一浏览，快速预览并显示别名、标签、时间与来源 | 无需打开文件目录即可判断素材是否可用 |
| 找得到 | 搜索同时匹配别名、文件名和标签名，并支持类型、素材组与时间筛选 | 用户能够用自己的命名和分类快速定位   |
| 用得快 | 支持单个、多选和素材组拖拽到生产区域                     | 拖入后可调整用途和顺序，无需复制文件 |
| 可维护 | 标签项目共享、素材组手动维护、删除进入回收站             | 组织规则稳定，误删可恢复             |

- 素材库与任务日志分离：素材库不展示处理中、失败或取消的任务。
- 别名与文件名分离：别名用于用户识别和搜索，不修改磁盘文件路径。
- 轻量组织优先：标签只描述素材；素材组保存用户明确加入的素材集合，不建立复杂目录树。
- 引用而非复制：拖入生产环境只传递素材引用，原文件保持单份。
- 手动编组、静态使用：素材组成员由用户拖入或多选加入；拖入生产环境后形成当次引用快照。

## 3. 已确认的产品规则

| 决策项       | 确认规则                                                         |
| ------------ | ---------------------------------------------------------------- |
| 入库范围     | 仅成功生成并已完成本地落盘的图片或视频自动进入素材库。           |
| 素材粒度     | 一次生成多个结果时，每个结果均为独立素材。                       |
| 素材命名     | 仅提供别名，不增加备注字段；预览卡片仅显示已设置的别名，不回退显示物理文件名。 |
| 标签作用域   | 标签属于项目，项目内成员均可查看、创建和使用。                   |
| 标签管理权限 | 标签创建者与项目管理员可重命名或删除标签。                       |
| 素材组       | 素材组由用户明确加入的多个素材组成。                             |
| 集合维护     | 用户可拖入素材或将当前多选素材加入；移除成员不修改素材本身。     |
| 拖拽顺序     | 按创建时间从早到晚排列；进入生产环境后可继续调整。               |
| 来源关系     | 任务日志可定位素材，素材详情可返回来源任务；不额外展示使用次数。 |
| 删除规则     | 先进入回收站；存在引用时二次确认，彻底删除作为独立操作。         |
| 工作区并行打开 | 素材库是独立工作区面板，可与其他项目资料同时打开；布局按项目在本地保存。 |
| 文件参数预览 | 生产区域的图片文件参数支持完整缩略预览与点击页内放大，本地上传图片与素材库引用使用一致交互。 |

## 4. 信息架构与页面结构

素材库作为独立工作区面板进入，不与生成任务状态混排。用户点击一级菜单“素材库”后打开或激活唯一的素材库面板，保留当前已打开的其他项目资料页面，默认展示全部未删除素材。页面以高密度浏览和重复操作为主，采用顶部搜索与筛选工具栏、中央素材网格、右侧详情面板的单页面结构；素材库内部不再增加第二层侧边栏或独立导航页。

| 区域       | 主要内容                                       | 核心动作                               |
| ---------- | ---------------------------------------------- | -------------------------------------- |
| 顶部工具栏 | 别名/文件名/标签名搜索、图片/视频类型、时间、素材组、排序 | 清空筛选、管理素材组、多选、批量打标签 |
| 中央网格   | 固定尺寸缩略图、别名、标签、创建时间           | 选择、预览、拖拽、批量操作             |
| 右侧详情   | 大图或视频预览、别名、标签、文件信息、来源任务 | 改别名、改标签、打开位置、进入来源任务 |

页面筛选结构：

```text
素材库：搜索（别名 / 文件名 / 标签名） + 类型下拉（全部素材 / 图片 / 视频） + 素材组 + 时间 + 排序
```

筛选与查询规则：

- 类型使用单选下拉菜单，默认展示项目内所有未删除的图片和视频；选择“图片”或“视频”时，同一网格仅展示对应类型，并可继续叠加素材组、时间与关键字条件。
- 顶部不提供单独的“标签”筛选控件；搜索框同时匹配素材别名、物理文件名和标签名称。标签仍用于素材详情编辑和批量打标签，标签管理通过详情区域的独立入口完成。
- “素材组”是手动维护的素材集合，同时提供创建、编辑和删除；选择素材组后，同一网格展示集合成员，素材组仍可直接拖拽。
- 回收站通过页面工具栏入口切换删除状态，但仍使用同一页面结构和筛选控件，不建立素材库内部侧边栏。
- 图片在卡片与详情中按完整画面显示，不裁切主体；视频在卡片和详情中提供页内播放、暂停、进度与音量控制。
- 生成图片在角色/场景、镜头及素材库中直接显示预览，完整显示画面；生产参数面板不再显示单独的生成结果区域。点击图片在当前页面放大查看，可通过关闭按钮、点击遮罩或 Esc 返回；一次生成多张图片时逐张预览。

### 4.1 工作区并行打开 2026-10-13

- 素材库可与小说、剧本、角色与场景、场次与镜头、任务日志等项目资料同时打开。打开素材库时保留当前资料面板及其编辑上下文；再次点击素材库只激活已有面板。
- 素材库使用统一工作区面板交互，支持并排停靠、拖拽排序、浮动、关闭和通过一级菜单重新打开。
- 面板布局按项目保存在本地，并兼容不含素材库面板的旧布局记录。切换项目时恢复目标项目布局，并重置素材库的搜索、筛选、选中素材和详情等界面状态，避免沿用前一项目的数据。
- 素材库正文仍为唯一素材页面，不新增内部第二层侧边栏。本地素材文件和项目数据继续由本地项目管理，GitHub 只负责源代码与评审。

### 4.2 文件参数预览 2026-10-15

- 生产区域的图片文件参数中，本地上传图片、素材库拖入图片和自动填入的项目图片均只显示 112 px 的完整缩略预览，不裁切画面；不显示资源地址、文件名或文件大小。图片卡片横向排列并按面板宽度换行，替换、排序和清除操作位于图片下方，添加图片入口位于字段标题旁。空输入仍可填写公开 URL。
- 点击参数中的图片，在当前页面放大查看；复用现有图片查看器，可通过关闭按钮、点击遮罩或 Esc 返回。
- 多张图片逐项预览，排序或替换后预览对应当前文件，移除或清空后不保留旧图；查看图片不修改参数值及用户顺序。
- 预览沿用本地文件与素材引用，不改变自动入库范围、拖拽快照或本地优先的数据管理边界。

### 4.3 场次目录与统一参考资料 2026-10-17

场次与镜头使用同一棵目录，每个场次下直接列出所属镜头，场次标题与箭头均支持点击展开、再次点击收起；切换正文不会强制重开刚收起的目录。选择场次显示场次编辑内容，选择镜头显示镜头编辑内容。其他页面的同类展开入口使用相同的再次点击收起交互，收起不清空已填内容或触发提交。

场次是故事结构，场景是可复用的地点资料。场景关联放在右侧参考资料卡片中，目录只负责导航。

角色、场景、首帧及其他已有参考素材统一使用预览区域、拖入选择和底部选择控件组成的卡片。角色可关联多个，每个角色有自己的图片与声音选择；完整对白功能保留。

镜头沿用所属场次已确认的角色与场景关联，直接显示实际参考图。角色图片或声音修改保存到所属场次；镜头参考图覆盖继续按镜头保存。2026-10-20 用户确认：单镜及分镜段自动填表时，仅按该范围结构化指令明确声明的角色解析默认参考图和声音；完整场次制作保留整场角色。尚无可用角色声明的旧数据或指令已过期时保留场次继承，不按姓名或正文猜测。人工选图、镜头覆盖及首帧继续保留，最终生成以用户表单为准。默认继承不写成镜头覆盖。

从素材库拖入卡片时校验当前项目、单张图片、有效状态与文件可读性；切换目标后丢弃旧的异步结果。图片完整显示并支持页内放大。普通提示词中的姓名或地点不直接建立关联，本地优先、静态引用快照与原有素材库规则保持有效。

角色与场景、场次与镜头页面优先展示提示词和绑定关系。四类提示词编辑框最低高度统一为 320 px，支持拖动右下角纵向调高，不能缩小到最低高度以下。角色/场景页按文档 ID 展示已绑定场次数量和跳转入口，声音设置与历史版本默认折叠；场次/镜头页在提示词后统一展示角色、场景与参考图，明确场次共享范围，助手关联和保存绑定集中在绑定区。衔接、分镜笔记、完整对白和配音作为次要操作展开使用；已绑定对白和失效衔接的状态仍明确显示。该调整只使用现有关系，不根据提示词或同名标题推断绑定。

2026-10-23 用户确认：角色、场景、道具按文档的实际类型独立归类，当前打开的文档也必须遵守目录类型筛选；切换筛选保留编辑器中未保存的内容。地点与环境属于场景，人物属于角色，独立物件属于道具；剧情不需要道具时允许道具列表为空，不为补齐类型创建占位资料。

单镜角色声明覆盖整个镜头实际可见的人物，包括背景、远景、无台词及收尾短暂入画的人物。Agent 根据语义使提示词与 IR 引用保持一致，系统只校验结构、文档 ID、项目和类型，不从正文姓名推断或补齐角色。明确的空角色数组表示无人物；新镜头省略角色范围时继承场次，修订省略时保留已有范围。已经保存的漏列引用需经 Agent 或用户明确修订，不自动改写。

### 4.4 镜头衔接抽帧 2026-10-18

人工选择上一镜头已成功保存的视频、画面时间点及一张衔接基准。预览候选帧只作为临时缓存，不进入素材库；人工确认后，本地抽帧成功落盘的原尺寸图片作为独立首帧素材入库，记录来源视频、内容哈希、时间点和本地任务，不修改原视频。

确认后才由支持看图的 LLM 根据已选画面、下一镜头内容和人工连续性要求生成可编辑提示词。同机位直接使用基准帧；换机位复用参考生图流程，人工确认新构图后再作为下一视频首帧。多张选帧不自动成为全部模型的必填输入。

衔接关系和首帧保存在当前项目 SQLite，带版本检查；源视频或图片被删除、剧情或镜头顺序变化时提示重新确认。被衔接引用的素材进入回收站前提示引用，解除衔接前不能彻底删除。项目文件仍本地保存，生成媒体沿用现有模型选择和费用确认。

### 4.5 素材预览卡片样式 2026-10-16

- 素材网格采用更大的方形预览区，图片与视频保持完整画面显示，不裁切主体。
- 卡片不显示物理文件名；仅在用户设置了别名时显示一行别名，过长省略并可悬停查看完整别名。没有别名或标签时不创建对应的信息行。
- 底部保留创建日期与文件大小，已添加的标签继续展示；选中、键盘选择、多选和拖拽沿用原有交互。
- 文件名仍可用于搜索，并在详情文件路径中查看；磁盘文件名、素材引用和本地存储规则不变。

### 4.6 场次角色媒体预览 2026-10-16

- 场次已绑定角色后，即使图片或声音样本稍后才准备好，也能预览角色默认资源；默认图片为该角色最早生成且仍有效的图片，新增图片不自动替换它，场次可指定其他图片或固定声音版本。
- “使用角色默认”“本场指定”“不使用”分别处理；明确不使用后，后续资源更新不自动补回。已有明确选择保持原引用，历史声音版本的文件有效时仍能试听，更新提示不替换原选择。
- 已选媒体按 ID 读取，不受素材库分页影响；只查询当前场次角色及其相关媒体，通过生成完成和声音变更事件刷新，不轮询或批量改写其他场次。
- 图片在可见时加载按内容哈希复用的真实缩略图，点击放大才读取原图；声音点击试听后才读取，播放器使用 preload=none。生成提交继续冻结实际输入，媒体文件保持项目本地单份引用，声音样本继续使用独立音频库。

### 4.7 生产参数面板收敛 2026-10-19

- 生产参数面板移除右侧“生成结果”区域，包括自动预览、空状态及重复的素材列表，参数表单使用面板全部宽度。
- 成功生成的图片和视频继续自动保存到本地素材库，角色/场景及镜头工作区继续显示所属生成图片；图片文件参数的输入预览保留。
- 视频任务的“查看素材”打开素材库并定位对应素材，系统播放器与打开位置入口保留。
- 制作页默认突出提示词与参考素材，模型选择后直接进入内容编辑；不展示模型详情。正常制作说明默认折叠，输出参数、专业参数和项目默认值集中在“更多设置”；阻塞制作或参数校验错误时自动展开相关区域。图片卡片仅在编辑地址时显示填写说明，没有视频任务或可选声音样本时不展示对应空区域。

## 5. 核心对象

| 对象     | 定义                                   | 关键属性                                           |
| -------- | -------------------------------------- | -------------------------------------------------- |
| 素材     | 成功生成并在项目中可用的单个图片或视频 | ID、类型、别名、路径、创建时间、来源任务、删除状态 |
| 标签     | 用户创建的项目级描述词                 | 名称、创建者、创建时间、关联素材                   |
| 素材组   | 保存的一组素材引用                     | 名称、素材集合、创建者、更新时间                   |
| 拖拽快照 | 拖拽开始时解析出的有序素材引用         | 项目 ID、素材 ID 列表、顺序、快照时间              |

> **术语边界** 标签回答“这是什么”；素材组回答“我要复用哪一批”。素材组不是父标签，也不会修改标签层级。

## 6. 核心用户流程

### 6.1 自动入库与整理

1. 生成任务成功，结果完成本地落盘并通过完整性校验。
1. 系统为每个结果建立独立素材记录，并保留来源任务关联。
1. 素材立即出现在“全部素材”和对应图片或视频视图中。
1. 用户按需设置别名，并给单个或多个素材添加项目标签。

### 6.2 查找与复用

1. 用户通过别名、物理文件名或标签名称关键字，以及类型、素材组和时间范围缩小结果。
1. 选择素材组时，只返回该组明确保存的素材成员。
1. 用户可通过拖放或当前多选创建素材组，之后直接打开或拖拽。
1. 素材组成员只在用户添加或移除时变化。

### 6.3 拖入生产环境

1. 用户拖拽单个素材、多选素材或素材组。
1. 系统在拖拽开始时解析可用素材，并按创建时间从早到晚排序。
1. 生产目标校验项目、素材类型与数量约束，再接受引用快照。
1. 目标区域依据自身语义分配用途；例如首尾帧区域接收两张图片，用户可交换顺序。
1. 拖入后即为生产草稿的一部分，后续标签变化不自动增减已拖入素材。

## 7. 关键交互规范

| 场景       | 交互规则                                           | 反馈                           |
| ---------- | -------------------------------------------------- | ------------------------------ |
| 设置别名   | 详情面板或卡片菜单内编辑；去除首尾空格；允许同名   | 保存后立即更新列表与搜索索引   |
| 批量打标签 | 多选后添加或移除标签，不覆盖未选择的其他标签       | 显示成功数量和失败项           |
| 创建素材组 | 输入名称，将素材拖入或将当前多选素材加入集合       | 显示当前成员数量               |
| 拖拽素材组 | 拖拽时解析当前成员；已删除或缺失文件的素材排除     | 拖拽浮层显示可投入数量         |
| 跨项目拖拽 | 第一版拒绝跨项目引用                               | 明确提示先导入或复制到当前项目 |
| 删除素材   | 移动到回收站；存在引用时二次确认                   | 可撤销或从回收站恢复           |

## 8. 状态与异常处理

- 空库：提示先完成一次图片或视频生成，不展示任务状态。
- 无搜索结果：保留筛选条件，提供清空筛选入口。
- 文件缺失：卡片标记“文件不可用”，禁止拖拽，并提供打开项目完整性检查。
- 标签已删除：素材解除关联，不影响素材组成员关系。
- 素材组无结果：允许保留素材组，但拖拽禁用并显示当前命中 0 项。
- 只读项目：允许查看、搜索和预览；禁用别名、标签、素材组、删除与拖拽写入生产草稿。

## 11. 验收标准

- 素材库中不存在处理中、失败、超时或取消的任务记录。
- 图片和视频成功落盘后自动出现，每个生成结果均可独立选择。
- 修改别名后，可立即通过新别名搜索到素材；文件名不发生变化。
- 输入素材的物理文件名或任一标签名称时，可搜索到对应素材；顶部不出现独立标签筛选控件。
- 选择素材组时，只返回该组明确保存的素材成员。
- 拖放或多选加入的素材会成为组成员；移除成员不会删除素材本身。
- 素材组拖入时按创建时间从早到晚排列，进入目标区域后可以重新排序。
- 拖入后标签变化不会改变生产草稿中的引用快照。
- 任务日志能够定位对应素材，素材详情能够打开来源任务。
- 删除进入回收站且可恢复；彻底删除需单独确认。
- 同一素材用于多个生产位置时不创建文件副本。
- 打开素材库后，当前小说、剧本、角色与场景、场次与镜头或任务日志仍可同时操作；素材库面板可停靠并排、拖拽排序、浮动、关闭和重新打开。
- 重新打开项目后恢复本地保存的面板布局；旧布局正常加载，不重复创建素材库面板。
- 切换项目后不保留前一项目的素材搜索、筛选、选中项和详情状态。
- 图片文件参数中，本地上传图片和素材库引用均只显示小缩略图，点击可页内放大；不显示资源地址或文件信息，排序、替换、移除与清空后仍对应当前输入。

提示词中的图片、音频、视频引用使用内联标签，图片标签包含缩略图。标签绑定当前模型参数中的真实素材，编号随提交顺序同步；替换或移除素材时旧引用不转绑其他素材。正文和模型参数保存在同一草稿快照，提交时标签转换为模型支持的提示词写法。删除正文中的标签只删除该处引用。制作面板和 Agent 审核表单共享实现，审核后直接提交。

2026-10-23 Agent 按需媒体读取：制作 Agent 可通过 `scene.read` / `production.read` 的 `view=media` 读取同一生产解析器得到的角色、场景和道具图片绑定，区分手动、默认、禁用和未选用，返回有界候选图、素材可用性及提交前的输入顺序；`asset.get` 返回受限的生成来源与输入素材 ID。候选图不等于选用图，未读取图片像素时不得声称看到了外观细节；IR 的文档引用继续使用文档 ID，不把 assetId 写入创作语义。普通会话仍按需读取，不自动注入整库素材。

## 并发任务实现更新

2026-10-17。统一并发计划已接入多项目运行上下文和按任务观察。激活另一项目或切换会话只改变界面订阅；显式卸载项目会停止该项目本地运行。任务和索引继续存储在本地项目 SQLite，GitHub 只管理源码和评审。
